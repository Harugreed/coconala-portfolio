## 紹介文（3行）

データ収集・CSV変換・請求書の自動作成・データ整形・リスト作成の自主制作サンプルです。
入力ファイル・スクリプト・出力ファイルを1組ずつ用意し、何を直したかを変更ログで確認できるようにしています。
ログインが必要な情報や認証の回避は扱わず、公開されている情報だけを対象に作業します。
