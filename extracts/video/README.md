## 紹介文（3行）

テロップ・図解入りの解説動画（約3分）・縦型ショート動画3本の自主制作サンプルです。
句読点での改行・強調語の色・章の見出しを仕様表で決めてから全編に当て、自動字幕のままの版と比べた動画も用意しています。
参考動画のテロップを再現する手順をマニュアルにまとめており、ご指定の雰囲気に合わせて作れます。
