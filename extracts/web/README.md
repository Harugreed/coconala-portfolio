## 紹介文（3行）

店舗HP3業種・団体の公式サイト・LP2本・リニューアル提案の自主制作サンプルを公開しています。
業種ごとに配色を写真や看板から拾い、骨格・書体・余白の密度まで変えて作っています。
営業時間・価格・アクセスを最初の画面に置き、スマホ幅375pxでの表示まで確認して納品します。
