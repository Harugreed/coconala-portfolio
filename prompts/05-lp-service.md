# P05 Web：サービス申込型LP（介護タクシー型）

架空の介護タクシーサービスのLPを作ってください。

【共通ルール（全プロンプト共通・厳守）】
- これはココナラ出品者「ハル｜よろずサポート屋」のポートフォリオ用サンプル制作である。実在の受注実績ではない。
- 成果物には必ず「自主制作サンプル」と明記する。実在店舗・企業を実績のように見せる表現、架空のお客様の声・受注件数・レビューは絶対に作らない。店舗・会社名は架空のものを使う。
- 品質基準：ココナラ同カテゴリの上位出品者のサンプルと並べて上位3位以内に入る水準まで、自分で評価→修正を最低2周繰り返してから完成とする。1回で終わらせない。
- 日本語の文章ルール：列挙に「と、」を使わず「、」のみ、並列は中黒「・」、時間範囲は空白なしの「〜」、価格は「〜から」を付けず言い切る。見出しは体言止め、本文は完結した文で書く。キャッチコピーや一言コメントは付けない。本文は事実だけを淡々と述べる。
- AI生成っぽい表現（過剰な絵文字、汎用的な美辞麗句、どこにでもある言い回し）は避ける。具体的な数字・固有名詞（架空でよい）・手順で書く。
- 成果物は指定の出力フォルダに保存し、最後に「作ったファイルの一覧・各ファイルの公開URL（GitHub Pages想定）・案件応募時にそのまま使える紹介文3行」を報告する。


【Web制作の追加ルール（デザイン仕様を先に作ること）】
- いきなりコードを書かない。まず同業種の実在する優良サイトを5件以上調べ、デザイン仕様を文章で固定してから実装する：基調色は3色以内（16進数で明記）、フォント名、見出しと本文のサイズ階層、余白の基準値、レイアウトの型、使わない要素（禁止事項）。
- 業種ごとに骨格から変える。他業種サンプルの使い回し・色違いだけの量産は禁止。
- 生成り・墨・赤の組み合わせを既定色にしない。配色はその店（架空）の看板・内装・料理の写真から抽出する形で決め、根拠を仕様に書く。
- 写真は彩度と明度を業種に合わせる（飲食は濃く、カフェは軽く）。フェードと陰影で奥行きを出す。スマホ表示を先に確認する。
- 静的HTML/CSS/JSのみ（ビルド不要）。GitHub Pagesでそのまま公開できる形にする。

【仕様】
- 目的は一般紹介ではなく「使い方の理解→申込」への導線。構成：利用場面（通院・買い物）、利用の流れ（予約から乗車・付き添い・帰宅まで）、料金、よくある質問、申込フォーム
- 初めての利用への不安を下げる順番で情報を置く。実写風の写真配置を前提にし、後から短い動画を差し込める枠を用意する
