# DESIGN.md — works/automation/（カテゴリ索引）

## コンセプト
「処理台帳」— 入力・スクリプト・出力の3点セットを、台帳の行として番号で読ませる索引。

## Bold move
各サンプルに特大の Archivo 数字（01／02／03）を割り、行ごとに「入力 → 処理 → 出力」の流れを罫線の帯で示す。数字がページの主役で、写真は台帳の添付資料として右端に小さく置く。

## 配色（3色）
- 地 #FAF3E4（クリーム）— 索引デザインシステム共通の地。基準ページ lp-video-studio と同じ
- 墨 #141110（インク）— 同上
- 差し #EF4A23（トマト）— 同上。数字と矢印だけに使う

## 書体
- 見出し・数字：Archivo（800、拡張幅気味）
- 英字アクセント：Playfair Display italic
- 日本語本文：Noto Sans JP（400／500／700）

## タイプスケール
基準16px／特大数字 7rem／h1 3.4rem／h2（サンプル名）1.5rem／本文 15px／注記 13px。行間 1.8。

## 余白スケール
8／16／24／32／48／64／96px。セクション余白 64〜96px、max-width 72rem。

## セクション順
1. 黒帯フラグ（自主制作サンプルの明記）
2. ヘッダー（戻りリンク＋英字ラベル Automation index）

4. 台帳リスト（01 スクレイピング実演／02 データ変換・Excel自動化／03 リスト作成）— 各行に説明・仕様（件数・形式）・実演スクリーンショット
5. フッター（サンプルの性質の注記＋戻りリンク）

- 全要素中央揃え
- word-break: keep-all と overflow-wrap: anywhere の併記
