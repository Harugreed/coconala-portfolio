# DESIGN.md — works/automation/list-sample/（詳細ページ）

## 種にした作例（参照プールから選定）
- 作例名：**Book Shelf**（出典：MotionSites / motionsites.ai、トップの作例一覧で確認 2026-11-26）
- なぜ合うか：本棚は「項目を棚板の上に等間隔で並べ、背表紙の情報で探す」構造であり、リスト見本の「行を並べ、列の値で探す」構造と一致する。リスト2種をそれぞれ1つの棚として見せる発想はこの作例から来ている。
- 借りる技法：(1) 棚板＝太い下罫線で区切られた横帯の繰り返し → 各リストを棚の帯として組み、帯の下端に太い罫線を引く。(2) 並んだ背表紙のように行を等密度で詰める → 抜粋表は行間を詰め、値そのものを読ませる。(3) 最終的な配色は作例からではなく題材（表計算シートと URL のリンク色）から導出する。
- コピーしないもの：作例の素材・文章・コード・配色は一切使わない。

## コンセプト
「形式見本そのもの」— ページ自体を1枚の表計算シートに見立て、実際の見本データの行を抜粋して載せる。

## Bold move
営業リストとインフルエンサーリストの実データ（架空データ S001〜S005／I001〜I005）を、行番号付き・見出し行固定風の本物の表としてページに埋め込む。説明文より先に表が来る。

- word-break: keep-all と overflow-wrap: anywhere の併記

## 事実の引き継ぎ（現行ページから）
- 営業リスト50行：会社名・業種・住所・URL・電話番号・メール・問い合わせフォームの有無・スマホ対応・備考・対応状況
- インフルエンサーリスト30行：アカウント・SNS・ジャンル・フォロワー数・規模・投稿数・平均エンゲージメント率・活動地域・依頼の受付

- 抜粋行は同梱 CSV の実データ（架空）S001〜S005／I001〜I005 をそのまま使う
- 成果物へのリンク先（相対パス）は現行のまま維持する
