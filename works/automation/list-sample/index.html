リスト作成サンプル（形式見本）

自主制作サンプル：形式を見せるための架空データです。会社名・URL・連絡先・アカウントはすべて架空で、URL・メールは実在しない予約済みの .example ドメインを使っています。実在の個人情報は含みません。

ファイル内容

influencer_list.xlsx ／ influencer_list.csvSNSインフルエンサーリスト（30行）：アカウント・SNS・ジャンル・フォロワー数・規模・投稿数・平均エンゲージメント率・活動地域・依頼の受付
make_lists.py見本データを作ったスクリプト

Excel 版の作り

  • 見出し行・左端の列を固定し、すべての列で絞り込みができます
  • 営業リストの「対応状況」は、未連絡・資料送付済み・返信あり・商談予定・見送り から選ぶ入力規則を設定しています
  • CSV 版は Excel で文字化けしないよう UTF-8（BOM付き）で保存しています

実案件で作る場合の進め方

  1. 対象（地域・業種・フォロワー数の範囲など）・必要な列を決めます
  2. 公開されている情報（各社のホームページ・公式アカウントのプロフィール）だけから集めます
  3. 営業メールを禁止している会社・個人のアカウント（企業でない方）の連絡先は載せません
  4. 集めた日付を記録し、古くなった情報を見分けられるようにします
