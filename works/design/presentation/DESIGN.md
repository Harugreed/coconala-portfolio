# DESIGN.md — プレゼン資料サンプル：白杢珈琲 様 集客のご提案（index.html 作り直し仕様）

## 種にした作例（参照プールから選定）

- **作例名：「Jobs | Pitch」（Pitch の LP）／出典：Landdding（landdding.com）** — https://landdding.com/similar-to/jobs--pitch-gpr11
  - なぜ題材に合うか：Pitch はプレゼンテーションを作る道具そのもので、その LP はタグ（web-app／big-type／animation／big-footer）が示す通り、1画面に1つのメッセージを大きなタイプで置く「スライドの文法」で Web ページを組んでいる。プレゼン資料の紹介ページも同じ文法で組むと、資料の中身（見出し＝結論1文）とページの見せ方が一致する。
  - 借りる技法（素材・文章・コードはコピーしない）：①1セクション＝1メッセージ、②見出しを大きく置き本文を短くする、③スライドカウンター（01 / 10）のようなクロームを各ブロックに付ける、④最後に大きなフッターで締める。本ページではカウンターを各スライドの番号ラベルとして実装する。
  - モーション（animation）は借りない。納品物が静止画のスライドであり、ページ側も静かな編集型にする。

## 導出

- 旧 index.html はスライド10枚そのものの HTML 版だった。作り直しでは「資料を読むページ」から「資料を紹介するページ」に変え、スライド画像（slides/slide-01〜10.png）を素材として再利用し、proposal-slides.pdf へのリンクを置く。スライド画像と PDF 自体は差し替えない。
- 配色・書体は資料自身（スライド）のブランドから取る：紙 #F6F7F6、焦げ茶 #2B211B、青緑 #2C6670、書体は Shippori Mincho B1 と Zen Kaku Gothic New。バナーページ（暗い棚）とは逆に、白い紙の編集型にする。

## 仕様

- コンセプト：結論の目次。10スライドの見出し（＝結論1文）を目次として先に並べ、その後にスライド全点をコンタクトシートで俯瞰させる
- **bold move：目次を「番号＋結論見出し＋図解の種類」の大きな編集表にし、スライド本体はキー3枚（表紙・方針・目標）を全幅、残りを2列のコンタクトシートで見せる。スライドを上から順に同じ大きさで積まない**
- 色（3色以内）
  - 紙：#F6F7F6 — スライドの地色そのもの
  - 墨：#2B211B — スライドの見出しと表紙の焦げ茶
  - 差し色：#2C6670 — スライドのキッカーとグラフに使われている青緑
- 書体：見出し Shippori Mincho B1 700、本文 Zen Kaku Gothic New 400/500/700
- タイプスケール（px）：56（h1）/ 32（目次の結論）/ 24（h2）/ 17（本文）/ 14（表・注記）/ 12（ラベル）。行間 本文1.8
- 余白スケール：8 / 16 / 24 / 32 / 48 / 64 / 96。セクション余白 96px
- セクション順
  1. ヘッダー：作品名・対象期間・納品形式の事実と PDF へのリンク
  2. 表紙スライド（全幅）
  3. 目次：10行の結論表（番号・結論見出し・図解）
  4. コンタクトシート：スライド2〜10（キー2枚を全幅、残り2列）
  5. 作り方：見出し＝結論1文、ブランドに合わせる、の事実
  6. ファイル表・応募時の紹介文・注記（数値は架空）
- 禁止要素
  1. スライド10枚を同じ大きさで縦に積まない
  2. 角丸カード＋影の量産をしない
  3. lp-video-studio の配色（#FAF3E4／#EF4A23）とモチーフを使わない
  4. スライド画像にキャプションを付けない（番号と図解名は外のラベルに置く）
  5. 紫〜青グラデーションを使わない
  6. 実在しない成果（受注・効果）を書かない。資料内の数値は架空と明記する
  7. スライド画像同士を重ねない
