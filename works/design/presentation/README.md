## 応募時の紹介文（3行）

架空のカフェへの集客提案を題材にした、10スライドのプレゼン資料の自主制作サンプルです。
各スライドの見出しを結論の1文にし、グラフ・流れの図・ガントチャート・表で中身を見せる図解中心の構成です。
PDF・画像・HTMLの3形式で納品でき、店のブランドの配色と書体に合わせて作っています。
