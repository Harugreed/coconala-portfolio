# DESIGN.md — Instagram投稿セット：白杢珈琲（作り直し仕様 v2）

## 参照作例（Haru共有のデザインライブラリ群から選定・2026-11-26）

- 選んだ作例：Mobbin の実アプリ画面「Instagram iOS Account Profile」（出典：mobbin.com）— https://mobbin.com/screens/5139b966-861e-4767-af30-560e310b36ec?section=key_screens
  - プロフィール情報（名前・投稿数などの要約）を上部に置き、その下に投稿を3列グリッドで並べる、Instagram 本来のプロフィール画面の構成。
  - なぜ合うか：このページの納品物は「店の Instagram 投稿セット」そのものなので、説明ページも Instagram のプロフィール画面の骨格で組むと、納品後の姿をそのまま見せられる。グリッドが第一印象になるという構造も題材と一致する。
  - 借りる技法：①プロフィール要約（店名・投稿6枚・1080×1080px などの数字）を上部に固める、②投稿は余白の少ない3列グリッドで隙間なく並べる、③詳細情報はグリッドの下に置く。素材・文章・コードはコピーせず、配色と書体は白杢珈琲自身のもの（P01 と投稿画像）から導く。

## コンセプトと bold move

- コンセプト：ページ自体を店の Instagram フィードに見立てる。投稿画像6枚を主役にし、説明はその後ろに置く。
- bold move：ヒーローを置かず、6枚の投稿画像を3列グリッドでページ最上部に大きく出す（フィード一覧そのものを冒頭に置く）。他の2ページ（縦型レール型／タイムライン型）とは骨格を変える。

## 配色（3色・出所付き）

- 地 #E4E7E5（ステンレス）：店のホームページ（P01）と投稿画像で使っているステンレスの色。投稿画像の地と同色にして、画像とページの境目を消す。
- 墨 #2B211B（焦げ茶）：同じく P01 と投稿画像の文字色。コーヒーの焦げ色。
- 差し色 #2C6670（焙煎機の緑）：店内の5kg焙煎機の色で、P01・投稿画像の見出し帯に使っている色。

## 書体・タイプスケール・余白

## セクション順

1. サンプル表記バー＋索引への戻りリンク
2. 題名と概要（投稿画像6枚・キャプション・1週間分の投稿カレンダー）

4. 投稿の中身（ファイル・内容・作りの方針の罫線リスト）

8. 応募時の紹介文（3行）

## 禁止要素

1. lp-video-studio の配色（#FAF3E4／#141110／#EF4A23）とモチーフの流用
2. 角丸カード＋影の量産グリッド（まとまりは余白と罫線で分ける）
3. 紫〜青グラデーション
4. 絵文字の箇条書き・アイコン代用
5. 写真同士を重ねる配置、縦長の切り抜き写真
6. 写真下の感想調キャプション（事実のラベルだけ置く）
7. `word-break: keep-all` と `overflow-wrap: anywhere` の併記
