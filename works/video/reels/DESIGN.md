# DESIGN.md — 縦型ショート動画3本（作り直し仕様 v2）

## 参照作例（Haru共有のデザインライブラリ群から選定・2026-11-26）

- 選んだ作例：MotionSites の「Boutique Rail」（出典：motionsites.ai、トップの作例一覧に掲載）
  - 商品や作品を横一列のレールに並べ、レール自体をページの主役にするヒーロー作例。
  - なぜ合うか：縦型ショート3本は「スマホが横に並んだ棚」として見せるのが最も速く伝わる。レールの作例は、並べた物そのものを冒頭に置き、説明を後ろに回す組み立てで、尺の違う3スタイルの比較にも向く。
  - 借りる技法：①作品を横一列のレールで冒頭に置く、②各アイテムに通し番号を付けて順序を持たせる、③説明はレールの下に回す。3Dやスクロール演出などの過剰なモーションは借りない（Haruルール：演出系は題材に合う範囲だけ）。素材・文章・コードはコピーせず、配色は3本の動画自身の画面色から導く。
- 補助参照：MotionSites の「Chef Stack」（出典：motionsites.ai）
  - 料理の作例を積み重ねて見せる作例。グルメ編の「カットを重ねて一気に見せる」感覚と合い、場面写真をストリップ状に連ねる見せ方の種にした。

## コンセプトと bold move

- コンセプト：縦型動画は縦のまま並べる。ページ全体を、スマホ3台が並んだ試写レールのように組む。
- bold move：ヒーロー文を置かず、3本の動画そのものを9:16のまま横一列に並べて冒頭に置く。各本の下に場面3枚のフィルムストリップを続け、動画→静止画で中身を確認できる二段構えにする。他の2ページ（フィード型／タイムライン型）とは骨格を変える。

## 配色（3色・出所付き）

- 地 #FFF2C6（クリーム）：クイズ編（reel-quiz）の画面の地に使っているクリーム色。3本の中で最も明るい画面色をページの地にする。
- 墨 #1E1E1E（黒）：クイズ編の吹き出しと文字の黒。
- 差し色 #FF6B3D（朱）：クイズ編のアクセントに使っている朱色。番号と罫線だけに使う。

## 書体・タイプスケール・余白

- 見出し：Zen Maru Gothic（グルメ編のテロップと同じ丸ゴシック、900）
- 本文：Noto Sans JP
- タイプスケール（px）：13 / 16 / 20 / 26 / 34 / 44、本文16px・行間1.8
- 余白スケール：8 / 16 / 24 / 32 / 48 / 64 / 96（8pt系）、最大幅 1120px
- ブレークポイント：768px / 1024px

## セクション順

1. サンプル表記バー＋動画一覧への戻りリンク
2. 題名と仕様の数字（3本・1080×1920・30fps・合計尺）
3. 動画レール（3本を9:16のまま横一列）
4. 本ごとの仕様（スタイル・尺・カット・書体・テロップの形・安全域を罫線リストで）
5. 場面のフィルムストリップ（1本につき代表場面3枚）
6. サムネイル6枚（1本につき2案）

## 禁止要素

1. lp-video-studio の配色（#FAF3E4／#141110／#EF4A23）とモチーフの流用
2. 動画を横長カードに切り取って並べること（縦型は縦のまま見せる）
3. 角丸カード＋影の量産グリッド
4. 紫〜青グラデーション、全面の黒地ヒーロー
5. 絵文字の箇条書き・アイコン代用
6. `word-break: keep-all` と `overflow-wrap: anywhere` の併記
