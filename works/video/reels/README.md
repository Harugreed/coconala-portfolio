# P09 縦型ショート動画3本（自主制作サンプル）

> 自主制作サンプル：1080×1920・30fps。店名・価格は架空のカフェ「白杢珈琲」（Web制作サンプル P01）のものです。素材映像・音楽は Mixkit、ナレーションは音声合成（Irodori-TTS）です。出典は ../telop/credits.md にまとめています。

## ファイル

| ファイル | 内容 |
|---|---|
| reel-gourmet.mp4 | グルメ紹介（20秒）：約2.8秒ごとのカット・角丸の札で品名と価格 |
| reel-biz.mp4 | ビジネスノウハウ（30秒）：黒地に大きな文字・ナレーション・進行バー |
| reel-quiz.mp4 | エンタメ（22秒）：3択クイズ・カウントダウン・正解で揺れと効果音 |
| spec.md | 3本それぞれのテロップとカットの仕様 |
| frames/ | 各動画の代表的な場面の画像 |
| ../thumbnail/out/ | サムネイル6枚（1本につき2案） |

制作に使った Remotion のコードは ../telop/source/src/Reels.tsx にあります。

## 応募時の紹介文（3行）

グルメ紹介・ビジネスノウハウ・クイズの3つのスタイルで作った縦型ショート動画の自主制作サンプルです。
スタイルごとに書体・テロップの形・カットの間隔・効果音を変え、アプリの操作ボタンと重ならない位置に文字を置いています。
1本につき2案のサムネイルも作り、動画と一緒に納品します。
