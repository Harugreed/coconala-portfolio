# DESIGN.md — YouTubeテロップ編集サンプル（作り直し仕様 v2）

## 参照作例（Haru共有のデザインライブラリ群から選定・2026-11-26）

- 選んだ作例：MotionSites の「Video Editor」（出典：motionsites.ai、トップの作例一覧に掲載）
  - 動画編集者のためのヒーロー作例で、編集ソフトのタイムラインを思わせる画面構成を持つ作例。
  - なぜ合うか：このページの納品物は「テロップ編集そのもの」であり、編集の仕事はタイムラインの上で起きる。ページの骨格をタイムライン（時間軸＋トラックの行）にすると、章構成・場面写真・仕様がすべて時間順に並び、編集者の作業画面を見る感覚で読める。
  - 借りる技法：①時間軸のルーラーとタイムコードをページの共通言語にする、②章を行（トラック）として積む、③本編タイトル画面の紺地＋黄色い線の組み立てをタイトル帯に使う。素材・文章・コードはコピーせず、配色は本編動画自身の仕様（図解の地・縁取りの紺・強調の黄色）から導く。

## コンセプトと bold move

- コンセプト：編集の「タイムライン」をページの骨格にする。章を時間順にたどれるページにする。
- bold move：本編の章構成9件を、タイムコード付きの縦タイムラインとしてそのままページの主セクションにし、各章の場面写真をタイムコードと並べる。他の2ページ（フィード型／縦型レール型）とは骨格を変える。

## 配色（3色・出所付き）

- 地 #EEF2F6（図解の地）：本編の図解場面の地の色（spec.md 3節）。
- 墨 #14213D（紺）：本編のタイトル画面の地とテロップの縁取りの紺。
- 差し色 #FFD43B（黄色）：本編の強調語と章見出しの帯の黄色。大きな面には使わず、線とタイムコードだけに使う。

## 書体・タイプスケール・余白

- 見出し・本文：M PLUS 1p（本編テロップと同じ書体、見出し800・本文400/700）
- タイムコード：ui-monospace（等幅）
- タイプスケール（px）：13 / 16 / 20 / 26 / 34 / 44、本文16px・行間1.8
- 余白スケール：8 / 16 / 24 / 32 / 48 / 64 / 96（8pt系）、最大幅 1120px
- ブレークポイント：768px / 1024px

## 禁止要素

1. lp-video-studio の配色（#FAF3E4／#141110／#EF4A23）とモチーフの流用
2. mp4 ファイルの差し替え（telop-main.mp4／before-after.mp4 は現行のまま）
3. 角丸カード＋影の量産グリッド
4. 紫〜青グラデーション
5. 絵文字の箇条書き・アイコン代用
6. `word-break: keep-all` と `overflow-wrap: anywhere` の併記
