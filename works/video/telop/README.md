## 制作の手順

1. 台本（source/script/telop-main.json）を文ごとに書き、強調語を [[ ]] で囲む
2. 文ごとにナレーションを合成し、時刻表（timing.json）を作る（source/tools/synth.py）
3. Remotion で、時刻表に合わせてテロップ・素材映像・図解・効果音を配置する（source/src/TelopMain.tsx）
4. 1280×720・H.264 で書き出し、代表的な場面の画像でテロップのはみ出し・重なりを確認する

## 応募時の紹介文（3行）

ビジネス解説風の動画（約3分）にテロップ・図解・強調演出を付けた自主制作サンプルです。

参考動画のテロップを再現する手順をマニュアルにまとめており、ご指定の雰囲気に合わせて作れます。
