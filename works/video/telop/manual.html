テロップ再現マニュアル

自主制作サンプル：依頼者から「この動画のようなテロップにしてほしい」と参考動画を渡されたときに、テロップを再現する手順をまとめたものです。A4で5ページ程度の分量です。手順の中のツールは、無料で使えるもの（ffmpeg・画像編集ソフトのスポイト・Google Fonts）に限っています。

1. 全体の流れ

  1. 参考動画から、テロップが出ている場面の画像を書き出す
  2. 書体の候補を絞り、手元の書体と重ねて比べる
  3. 文字・縁取り・影・帯の色を、画像から数値で拾う
  4. 大きさ・位置・行の上限を、画面の大きさに対する比で測る
  5. 出かた・消えかた・表示時間を、フレーム単位で測る
  6. 拾った値を仕様表にまとめ、依頼者に確認してから全編に当てる

仕様表を先に作るのは、制作の途中で「前半と後半でテロップの大きさが違う」といったずれを防ぐためです。本編の仕様表は spec.md を見本にしてください。

2. 参考動画から画像を書き出す

2-1. テロップが出ている場面を探す

参考動画を再生し、次の3種類の場面の時刻をメモします。

  • 本文のテロップが1行の場面・2行の場面
  • 強調語（色や大きさが変わっている語）がある場面
  • 章の見出しや、画面の端に出る小さな文字がある場面

2-2. その時刻の画像を書き出す

ffmpeg で、メモした時刻の1フレームを PNG で書き出します。動画の解像度のまま書き出すことが大切です。縮小した画像では、縁取りの太さが正しく測れません。

```
ffmpeg -ss 00:01:23.40 -i reference.mp4 -frames:v 1 frame_0123.png
```

テロップが出てから消えるまでを調べるときは、その前後を1フレームずつ書き出します。

```
ffmpeg -ss 00:01:23 -t 2 -i reference.mp4 -vf fps=30 seq_%03d.png
```

30fps の動画なら、2秒で60枚の画像になります。テロップが最初に見えた番号・完全に表示された番号・消えた番号を記録しておくと、5章の時間を測るときに使えます。

3. 書体の候補を絞る

3-1. 字の形で分ける

書き出した画像を拡大し、次の点を確認します。

確認する点見分けられること
線の端が丸いか角か丸ゴシック系か、角ゴシック系か
縦と横の線の太さが同じかゴシックか、明朝か
「あ」「な」「ふ」のふところの広さ字面が大きい書体か、小さい書体か
「さ」「き」がつながっているか手書き風・デザイン書体かどうか
数字の「1」「7」の形欧文の書体を別に組み合わせているか

3-2. 候補を重ねて比べる

候補の書体で同じ文字を打ち、参考画像の上に半透明で重ねます。線の太さ・字の幅・「ー」の長さが合う書体を選びます。

  • 商用利用できる書体を候補にします。Google Fonts の書体（M PLUS 1p・Noto Sans JP・Zen Maru Gothic など）は SIL Open Font License で、動画への使用ができます
  • 参考動画の書体が有料の書体と分かった場合は、依頼者が使用許諾を持っているかを確認します。持っていない場合は、形の近い無料の書体を2〜3案出して選んでもらいます
  • 書体名を断定できないときは、仕様表に「○○に近い形の書体として△△を使用」と書き、推測であることを残します

4. 色・大きさ・位置を測る

4-1. 色を拾う

画像編集ソフトのスポイトで、次の4か所の色を拾います。

拾う場所注意点
文字の中心縁に近い部分は、縁取りと混ざった色になるので避ける
縁取りの中心縁取りが2重のときは、内側・外側を別々に拾う
影影は背景と混ざるので、背景が白に近い場面で拾う
帯・座布団（文字の後ろの図形）半透明のときは、背景が黒の場面と白の場面の両方で拾い、透明度を計算する

動画は圧縮で色が少しずれます。同じ場所を3つの場面で拾い、中央の値を採用します。拾った色は16進数（例 #FFD43B）で仕様表に書きます。

4-2. 大きさと位置を比で測る

画面の大きさが違う動画に当てられるよう、ピクセルではなく画面に対する比で測ります。

測る値測り方本編の例（1280×720）
文字の大きさ漢字1字の高さ ÷ 画面の高さ46 ÷ 720 = 6.4%
縁取りの太さ縁取りの幅 ÷ 文字の大きさ9 ÷ 46 = 約20%
下からの位置2行目の下端から画面の下端まで ÷ 画面の高さ54 ÷ 720 = 7.5%
1行の字数いちばん長い行の字数を数える20字

1920×1080 の動画に当てる場合は、比をかけ直します（文字の大きさ 1080 × 6.4% = 69px）。

5. タイミングを付ける

5-1. 参考動画の出かた・消えかたを測る

2-2 で書き出した連番の画像で、次の3つを数えます。

  • 現れ始めてから完全に表示されるまでのフレーム数（本編は4フレーム）
  • 動き方（その場で現れる・下から上がる・左から滑る・大きくなる）
  • 話し終わってから消えるまでのフレーム数（本編は約8フレーム）

5-2. 自分の動画に当てるときの決まり

本編では、次の決まりでタイミングを付けました。

  1. テロップは、その文を話し始めるフレームで出す。話し始めより早く出すと、視聴者が先に読んでしまい音声と合わなくなる
  2. 文が長く3行以上になるときは、2行ずつのページに分け、字数の割合で表示時間を配る
  3. 次の文までの間が短いときも、同じテロップを0.5秒以上は表示する
  4. 章が変わるときは、章の見出しを先に出し、本文のテロップはその後に出す

5-3. 文ごとの時刻を取る方法

ナレーションを文ごとに別の音声ファイルとして作ると、各ファイルの長さから文の開始時刻が計算できます。本編では、台本の各文を音声合成で読み上げ、文の長さと文の間（0.45秒）を足し合わせて、すべてのテロップの開始時刻を自動で決めています（source/tools/synth.py が作る timing.json）。

人の声を収録した動画の場合は、文字起こしツールの単語ごとの時刻を使うか、波形の無音の部分を目で見て区切ります。

6. 改行と表記の決まり

自動字幕のままでは読みにくくなる主な原因は、改行の位置と表記の揺れです。本編では次の決まりを使いました。

決まり理由
改行は読点の位置を優先し、次に助詞（は・が・を・に・で など）の後ろで切る意味の切れ目で改行すると、1行ずつ読んでも意味が分かる
単語・強調語の途中では改行しない「営業時」「間」のように切れると読み返しが起きる
文末の「。」は表示しないテロップの行末がそろい、画面がすっきりする
固有名詞・数字は台本の表記に統一する自動字幕は「Googleマップ」を「グーグルマップ」、「口コミ」を「口込み」と誤ることがある
強調語は1文に2〜3語まで強調が多いと、どれが大事か分からなくなる

比較動画（before-after.mp4）で、同じ音声の自動字幕風の表示・この決まりで作ったテロップを並べています。

7. 仕様表の作り方と確認

拾った値は、次の項目で仕様表にまとめます（spec.md を見本にしてください）。

  1. 書体・大きさ・1行の字数・行数
  2. 文字・強調・縁取り・影・帯の色（16進数）
  3. 位置（画面に対する比・実際のピクセル）
  4. 出かた・消えかた・表示時間（フレーム数）
  5. 章の見出しなど、本文以外のテロップの仕様

依頼者には、仕様表と「1行の場面」「2行の場面」「強調語がある場面」の3枚の画像を先に送り、確認をもらってから全編に当てます。全編に当てた後で書体や色を変えると、すべての場面の確認をやり直すことになるためです。

8. 納品前の確認項目

  • テロップの誤字・脱字がない（台本と1文ずつ照らし合わせる）
  • 3行以上になっている画面がない
  • 単語の途中で改行している箇所がない
  • テロップが図や人物の顔に重なっていない
  • 話し始めとテロップの出るタイミングがずれていない（10か所を抜き出して確認する）
  • スマートフォンの画面で読める大きさになっている
