# テロップ仕様表：Googleマップで見つけてもらう3つの準備

> 自主制作サンプル：本編動画（telop-main.mp4）で使ったテロップの仕様です。値は Remotion のコード（source/src/TelopMain.tsx の SPEC）と同じです。

## 1. 本文テロップ（話している言葉）

| 項目 | 値 |
|---|---|
| 書体 | M PLUS 1p ExtraBold（SIL Open Font License） |
| 大きさ | 46px（1280×720の画面に対して。1920×1080なら69px） |
| 1行の上限 | 全角20字。超える文は読点 → 助詞の後ろ → 中央の順で改行する |
| 1画面の行数 | 2行まで。3行以上になる文は、2行ずつのページに分けて切り替える |
| 文字の色 | #FFFFFF |
| 強調語の色 | #FFD43B（台本で [[ ]] に囲んだ語） |
| 縁取り | #14213D・9px（文字の外側に付ける） |
| 影 | 下に4px・ぼかし10px・黒の35% |
| 位置 | 画面の下から54px・左右中央 |
| 文末 | 「。」は表示しない |
| 出かた | 4フレーム（約0.13秒）で、下から10px動きながら現れる |
| 消えかた | 読み終わってから0.25秒後に消える（次の文との間は0.45秒） |

## 2. 章の見出し（左上）

| 項目 | 値 |
|---|---|
| 書体・大きさ | M PLUS 1p ExtraBold・24px |
| 色 | 地 #14213D・文字 #FFFFFF・左の帯 #FFD43B（幅10px） |
| 位置 | 画面の上から34px・左端に付ける |
| 出かた | 章が変わったときだけ、10フレームで左から40px滑り込む。切り替わりに効果音（whoosh）を音量18%で鳴らす |

## 3. 図解の場面

| 項目 | 値 |
|---|---|
| 地の色 | #EEF2F6 |
| 文字・図形 | #14213D・強調は #FFD43B・グラフの最新月は #2A6F97 |
| 動き | 要素ごとにばね（damping 14・stiffness 140）で現れる。ナレーションで触れた瞬間に出す |
| 配置 | 本文テロップと重ならないよう、図解は画面の上から約560pxまでに収める |

## 4. 素材映像の場面

- 6秒ごとに素材を切り替え、各カットで1.00倍 → 1.07倍にゆっくり寄る
- 画面の下半分に黒の55%→0%のグラデーションを敷き、テロップを読みやすくする

## 5. 音

| 項目 | 値 |
|---|---|
| ナレーション | Irodori-TTS（MIT License）でローカル合成。文ごとに WAV を作り、文の間は0.45秒・場面の間は0.8秒 |
| BGM | Mixkit「Motivating Mornings」・音量7%・繰り返し |
| 効果音 | Mixkit の whoosh・章の切り替わりだけ |
