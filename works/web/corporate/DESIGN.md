# デザイン仕様：一般社団法人 えんぴつ学習ネット（架空・自主制作サンプル）v2

さくら台市（架空）で放課後の無料学習室を3か所運営する一般社団法人の公式サイト（5ページ）。
制作ルールは `../../../WEB_RULES.md` と共通ブリーフ（portfolio-v2-brief）に従う。
事実（法人名・事業内容・役員・沿革・数字等）は v1 の各ページからそのまま引き継ぐ。追加した事実はない。リンク構造（5ページ＋ページ内アンカー）も維持する。

## 参照プールの作例（主参照）

**Landdding「Charity」カテゴリ**（LP作例集 landdding.com のチャリティ分類：https://landdding.com/c/charity、作例3件をキュレーション）

なぜ合うか：一般社団法人の公式サイトはLPではないが、「支援するかどうかを判断する読み手に、団体の実態を正確に伝える」という仕事はチャリティLPと同種であるため。Landdding の編集方針は「Charity landing pages live or die by specificity（具体性で決まる）。一般的なヒーロー文句・ストック写真・ビュッフェ式のCTAは弱いページの印で、鋭い位置づけ・実物の画像・1つの明確な次の行動が強いページの印」と明記している。借りる技法はこの判断基準だけ（素材・文章・コードはコピーしない）：

- 具体性で信頼を作る → 冒頭の数字の帯（3か所・48人・20人・年4回、すべて現行ページの事実）と、基本情報・役員・沿革の表組みを主役にする
- 実物の画像を使う → 同梱済みの実写真2枚（学習室・ボランティア）をそのまま使う。写真の上に文句を重ねない
- 次の行動を明確にする → トップの「よく使う3項目」と各ページ末尾の導線を、リンク先が実在するものだけに絞る
- 一般的なヒーロー文句を置かない → トップの見出しは団体の活動を述べる事実文のままにする

### 調査からの導出

- 冒頭に数字の帯を置く（チャンス・フォー・チルドレンの「数字で課題を示す」型から）。ただし声・口コミは捏造になるため使わず、数字と表だけで信頼を作る
- 地は白、主色は1色に絞る（Learning for All の白＋1色から）。色は調査先の緑を借りず、題材自身のロゴ（鉛筆）の芯の鉛色と軸の黄から取る
- 事業は対象・日時・場所・費用の表組みで立場ごとに読める形にする（キッズドアの対象者別案内から）
- 書体は公的文書の読みやすさを優先し、ユニバーサルデザイン書体の BIZ UDPゴシックにする

## コンセプト（1つ）

**公文書の精度。** 罫線・番号・表組みで読み進める公式文書として組む。装飾は団体ロゴの鉛筆の黄と芯の鉛色だけに絞り、信頼感は文章の正確さと表の整い方で作る。

## Bold move（1つ）

トップページの冒頭に、**団体の数字だけを大きな活字で並べる黄色の帯**を置く。学習室3か所・登録ボランティア48人・各学習室の定員20人・進路相談会 年4回。数字は64px（スマホ48px）の太字で出し、根拠はすべて現行ページに載っている事実に限る。

## 配色（3色）と出所

出所：主色と差し色は団体ロゴの鉛筆から拾った。芯の鉛色が主色、軸の黄色が差し色で、黄色は学習室の黄色い机の写真（img/study.jpg）にも通じる。地の白は公的機関のサイトの慣習に合わせた。

| 役割 | HEX | 用途 |
|---|---|---|
| 地 | `#FFFFFF` | 全ページの地 |
| 主色 | `#2B3038` | 鉛筆の芯の鉛色。見出し・罫線・フッター・ナビ |
| 差し色 | `#E8C53A` | 鉛筆の軸と学習机の黄色。数字の帯・現在位置の印・見出しの縦線 |

リンクの青 `#1D4E89` は識別のための機能色（下線付き）としてのみ使う。罫線 `#D9DBDF` と面 `#F4F5F6` は主色の階梯として使う。

## 書体

- 全文：BIZ UDPゴシック（400・700）。読みやすさを優先したユニバーサルデザイン書体で、自治体・教育機関の文書でも使われる
- 数字の帯の数字も同書体700で出す（書体を増やさない）

## セクション順（骨格）

共通：サンプル表記 → ヘッダー（白地：ロゴ・団体名・事務局電話）→ グローバルナビ（白地の下線タブ、現在ページに黄色の下線）→ パンくず（下層のみ）→ 本文 → フッター（鉛色地）

- トップ：見出し＋基本事実の表（右）→ 写真（横長・全幅）→ 数字の帯（黄地）→ お知らせ最新5件 → 事業内容3行 → 開室日の表 → 団体について
- 下層4ページ：左にページ内リンクの細い柱（このページの目次）、右に本文（見出し＋表組み）の2列構成

v1（全幅の暗いナビ帯＋1カラム）とはナビの形と下層の骨格が違う。shop-ramen（藍と金の密な食券型）とも地・主色・骨格は重ならない。

## 改行の実装

日本語の表示行は意味の塊ごとに `<span class="nb">`（nowrap）でマークアップし、改行は塊の境目でのみ起こす。行単位の短文は `<span class="seg">`（block）。行に分けた短文は行末の句読点（。も、も）を省く。`word-break: keep-all` と `overflow-wrap: anywhere` の併記はしない。表の中の文は通常の本文として文末の「。」を残す。

## 禁止要素（6つ）

1. 写真の上に重ねたキャッチコピー、自動で回るスライダー
2. 角丸＋影のカード、中央揃えの均一グリッド
3. 存在しないPDFへのリンク（情報公開は「事務局で閲覧」と案内する）
4. 送信できるように見えるフォーム（送信ボタンは無効化し、サンプルである旨を表示する）
5. 実在しない実績・数字の追加（数字は現行ページの事実だけを使う）
6. 絵文字の箇条書き・アイコン

## 更新しやすさのための作り

- お知らせは `assets/news-data.js` の配列に1件足すだけで、トップの最新5件・一覧ページの年別表示・種類の絞り込みに反映される
- 共通のスタイルは `assets/common.css` の1ファイル。トップページ固有のスタイルだけ index.html 内の `<style>` に置く
- ヘッダー・フッター・ナビは全ページ同じ構造
