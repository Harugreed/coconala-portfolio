# デザイン仕様：一般社団法人 えんぴつ学習ネット（架空・自主制作サンプル）

さくら台市（架空）で放課後の無料学習室を3か所運営する一般社団法人の公式サイト（5ページ）。
制作ルールは `../../../WEB_RULES.md` に従う。

## 1. 参考にした同種サイト（2026-11-22 確認）

| サイト | URL | 地色・本文書体 | 読み取れた点 |
|---|---|---|---|
| チャンス・フォー・チルドレン | https://cfc.or.jp/ | 白・Noto Sans JP | 理事・監事の紹介、決算書・事業報告書をナビに置く |
| Learning for All | https://learningforall.or.jp/ | 白・游ゴシック | 「メインコンテンツへ」のスキップリンク、寄付・ボランティアへの導線 |
| キッズドア | https://kidsdoor.net/ | 白・Zen Kaku Gothic New | 事業を対象者ごとに分けて案内する |
| 東京都教育委員会 | https://www.kyoiku.metro.tokyo.lg.jp/ | 白・Noto Sans JP | 公的機関の情報の並べ方（お知らせ一覧・種類表示） |
| デジタル庁 | https://www.digital.go.jp/ | 白・Noto Sans JP 17px | 本文17px・下線付きリンク・強いフォーカス表示 |

## 2. 前回作との差

同じ種類（法人・団体の公式サイト）の前回作はない。本シリーズの店舗HP3件（ステンレス・金と藍・青灰）とも地・主色・骨格が重ならない。骨格は公的機関の型（ヘッダー＋全幅のグローバルナビ＋パンくず＋表組み）にした。

## 3. 配色（3色）と出所

| 役割 | HEX | 出所 |
|---|---|---|
| 地 | `#FFFFFF` | 公的機関のサイトに合わせた白 |
| 主色 | `#2B3038` | 団体名の「えんぴつ」の芯の黒鉛色。ロゴの芯の色と同じ |
| アクセント | `#E8C53A` | 学習室の黄色い机（study.jpg の #CCB740 を明るくした色）。ロゴの軸の色と同じ |

リンクは識別のため #1D4E89 の青・下線付きにしている（アクセシビリティの慣習に合わせた機能色）。

## 4. 書体

- BIZ UDPゴシック（400・700）。読みやすさを優先したユニバーサルデザイン書体で、自治体・教育機関の文書でも使われる

## 5. 文字サイズの段階（PC／スマホ）

| 要素 | PC | スマホ |
|---|---|---|
| ページ見出し | 34px | 26px |
| トップの見出し | 30px | 22px |
| セクション見出し | 26px | 22px |
| 小見出し | 20px | 20px |
| 本文 | 17px | 16px |
| 注記 | 14px | 14px |

## 6. 余白の段階

4・8・16・24・40・64・96px の7段階。セクション上下 64px（スマホ 40px）。

## 7. レイアウトの型

```
┌ サンプル表記 ─────────────────────────────┐
│ ロゴ・団体名                 事務局の電話番号     │
│ ■トップ■事業内容■団体概要■お知らせ■お問い合わせ │ ← 全幅のナビ。現在のページに黄色の下線
├ パンくず（下層のみ） ─────────────────────────┤
│ トップ：写真（横長）→ 一文の説明＋よく使う3項目     │
│        お知らせ最新5件 → 事業3行 → 開室日の表 → 団体│
│ 下層：ページ見出し（黄の縦線）→ 見出し＋表組み      │
├ フッター：所在地・電話・サイトマップ ─────────────┤
```

## 8. 更新しやすさのための作り

- お知らせは `assets/news-data.js` の配列に1件足すだけで、トップの最新5件・一覧ページの年別表示・種類の絞り込みに反映される
- ヘッダー・フッター・ナビは全ページ同じ構造。ページを増やす場合は既存ページを複製して `<main>` の中だけを書き換える
- 共通のスタイルは `assets/common.css` の1ファイル

## 9. 使わない要素

- 写真の上に重ねたキャッチコピー、自動で回るスライダー
- 角丸＋影のカード、中央揃えの均一グリッド
- 存在しないPDFへのリンク（情報公開は「事務局で閲覧」と案内）
- 送信できるように見えるフォーム（送信ボタンは無効化し、サンプルである旨を表示）
