# P04 法人・団体の公式サイト「一般社団法人 えんぴつ学習ネット」（自主制作サンプル）

地域の学習支援団体（架空）の公式サイトです。5ページ構成です。

## 見かた

- `index.html` をブラウザで開くと表示できます（Google Fonts を読むためネット接続が必要です）
- 公開URL（GitHub Pages 想定・未公開）：https://harugreed.github.io/coconala-portfolio/works/web/corporate/
- 画面写真：`screenshots/` に PC・スマホの最初の画面とトップ全体

## ページ

| ファイル | ページ | 主な内容 |
|---|---|---|
| index.html | トップ | 写真・団体の説明・よく使う3項目・お知らせ最新5件・事業・開室日の表・団体情報 |
| business.html | 事業内容 | 3事業の説明と実施要項（対象・日時・場所・費用・申込） |
| about.html | 団体概要 | 基本情報・役員・沿革・情報公開・事務局の所在地 |
| news.html | お知らせ | 年別一覧・種類の絞り込み・開いて本文を読む |
| contact.html | お問い合わせ | 電話の案内・フォーム（見た目のみ・送信機能なし） |

## お知らせの更新方法

`assets/news-data.js` を開き、配列のいちばん上に次の形で1件追加して保存します。HTMLの編集はいりません。

```js
{ date: "2026-12-01", cat: "info", title: "見出し", body: "本文1行目\n本文2行目" },
```

`cat` は `info`（お知らせ）・`recruit`（募集）・`report`（活動報告）のいずれかです。

## 実案件で差し替える箇所

- お問い合わせフォーム：送信ボタンを無効にしています。実案件ではフォーム送信サービスまたはサーバーの送信処理を接続します。
