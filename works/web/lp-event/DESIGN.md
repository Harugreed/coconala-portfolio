# デザイン仕様：中小店舗のためのInstagram集客講座（架空・自主制作サンプル）

中小店舗の経営者向けオンライン講座（90分・Zoom・参加費2,000円）の申込LP。
制作ルールは `../../../WEB_RULES.md` に従う。

## 1. 参考にしたサイト（2026-11-22 確認）

| サイト | URL | 読み取れた点 |
|---|---|---|
| Peatix | https://peatix.com/ | イベントページで日時・形式・参加費を最初にまとめて見せる |
| connpass | https://connpass.com/ | 開催日時・定員・申込締切を表にする |
| ストアカ | https://www.street-academy.com/ | 講座の対象者・講師の経歴・内容の時間割を分けて載せる |
| Doorkeeper | https://www.doorkeeper.jp/ | 申込から参加URLの受け取りまでの流れを示す |
| Instagram for Business | https://business.instagram.com/ | 講座の題材。プロフィール・投稿の用語を合わせる |

## 2. 前回作との差

同じ種類（イベント集客LP）の前回作はない。本シリーズの他作品とは、最初の画面を「切り取り線のある入場券」の形にした骨格で差を付けた。

## 3. 配色（3色）と出所

| 役割 | HEX | 出所 |
|---|---|---|
| 地 | `#FFFFFF`（区切りの面に #F7F1F2） | 白。区切りの面は主色を薄くした色 |
| 主色 | `#7E3348` | オンラインで参加している人の上着のローズ（online.jpg の #964A59 を暗くした色） |
| アクセント | `#E0A64B` | スマートフォンで撮っている焼き菓子の焼き色（shoot.jpg の #B68042 を明るくした色） |

Instagram のロゴの紫〜橙のグラデーションは使わない（商標・禁止事項の両方の理由）。

## 4. 書体

- 見出し・日時：Dela Gothic One（日時の数字を大きく太く見せる）
- 本文：IBM Plex Sans JP（400・600）

## 5. 文字サイズの段階（PC／スマホ）

| 要素 | PC | スマホ |
|---|---|---|
| 講座名 | 46px | 30px |
| 日付 | 54px | 42px |
| セクション見出し | 32px | 26px |
| 時間割の時刻 | 28px | 22px |
| 本文 | 16.5px | 15.5px |

## 6. 余白の段階

8・16・24・40・64・112px。セクション上下 112px（スマホ 64px）。見出しは左の列（15em）、本文は右の列。

## 7. レイアウトの型

```
ローズの地：主催・講座名・一文の説明 ｜ 入場券（日時を大きく／形式・参加費・定員・締切）
写真（横長・全幅）
対象 → 内容（時間割）→ 参加のしかた（写真＋3手順）→ 講師 → 申込フォーム → 注意事項
```

## 8. 使わない要素

- 参加者の声・「満席続出」・残席の煽り、カウントダウン
- 講師の顔写真（架空の講師に実在の人物の写真を当てないため、頭文字の印にした）
- 送信できるように見えるフォーム（送信ボタンは無効化）
