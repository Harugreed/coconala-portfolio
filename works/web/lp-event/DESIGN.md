# デザイン仕様：中小店舗のためのInstagram集客講座（架空・自主制作サンプル）v2

中小店舗の経営者向けオンライン講座（90分・Zoom・参加費2,000円）の申込LP。
制作ルールは `../../../WEB_RULES.md` と共通ブリーフ（portfolio-v2-brief）に従う。事実・日時・料金・リンクは v1 から引き継ぐ。

## 参照プールから選んだ種（2026-11-26 確認）

| 種にした作例 | 出典 | なぜ題材に合うか・借りる技法 |
|---|---|---|
| 「Paper Craft」 | MotionSites（motionsites.ai） | 紙を折り重ねた印刷物の世界観の作例。セミナー当日に配るプログラム冊子は紙の印刷物であり、フラットな紙の面・印刷らしいタイポグラフィ・面ごとに区切る構成が、講座LPの「概要 → 時間割 → 講師 → 注意事項」という冊子の流れと一致する。借りるのは紙の面と組版の技法（帯状のパネル、影に頼らない平らな面、印刷物の見出し階層）だけで、素材・文章・コードはコピーしない |
| 「Book Shelf」 | MotionSites（motionsites.ai） | 本という印刷物を題材にした作例。背表紙・目次のように情報を定型の並びで見せる感覚を、開催概要の台帳と時間割の定型反復に借りる |

導出：種の「紙の印刷物」の技法で、当日配布のプログラム冊子の組版を骨格にする。日付の帯（帯状パネル）・概要の台帳・時間割を本文より先に置き、見出しは冊子らしい明朝、数字は日付と時刻が一目で読めるグロテスクで組む。最終配色は題材の写真（shoot.jpg の焼き色、online.jpg のローズ）から導出する（下記）。Instagram のロゴの紫〜橙グラデーションは使わない（商標・禁止事項の両方の理由）。

## コンセプト（1つ）

プログラム冊子型LP。講座名・日付・概要・時間割・講師・注意事項を、セミナー当日に配るプログラムと同じ順序と型で並べる。

## Bold move（1つ）

日付「2027.1.16」を主色の帯に Barlow 72px で打ち出し、その直下に形式・参加費・定員・締切の概要台帳を置く。時間割の時刻も 28px の数字で組み、ページ全体を「日付と時刻」で読ませる。

## 配色（3色）と出所

| 役割 | HEX | 出所 |
|---|---|---|
| 地 | `#FFFFFF`（区切りの面に主色を薄めた `#F7F1F2`） | プログラム冊子の紙の白。区切り面は主色の階梯 |
| 主色 | `#7E3348` | online.jpg でオンライン参加している人の上着のローズ（#964A59）を暗くした色。日付の帯と見出しに使う |

## 書体

- 日付・時刻の数字：Barlow（600）— 開催概要の数字を一目で読ませる
- 日本語見出し：Noto Serif JP（700）— プログラム冊子の格
- 本文：Noto Sans JP（400・700）、16px、行間1.9

## セクション順（骨格：冊子の余白列＋日付の帯）

1. 主催・講座名・1文の説明
2. 日付の帯（2027.1.16 土 14:00〜15:30）＋概要台帳（形式・参加費・定員・締切）＋申込導線
3. 写真（shoot.jpg・横長・全幅）
4. 対象（3項目）
5. 内容（時間割4行＋録画の注記）
6. 参加のしかた（online.jpg＋3手順）
7. 講師（頭文字の印・名前・所属・経歴）
8. 申込フォーム（送信ボタンは無効化したサンプルのまま）
9. 注意事項（4項目）
10. フッター（主催・問い合わせ・サンプルの明記）

## 禁止要素（6つ）

1. 参加者の声・「満席続出」・残席の煽りとカウントダウン
2. 紫〜橙グラデーション（Instagramロゴの模倣）と全面グラデーションのヒーロー
3. 角丸カード＋影の量産と均一グリッド
4. 講師の顔写真に実在の人物の写真を当てること（架空の講師のため頭文字の印のまま）
5. 絵文字の箇条書き・アイコン代用
6. 写真同士を重ねる配置と写真キャプション

## 改行の実装

日本語の表示行は意味の塊ごとに `<span class="nb">`（nowrap）でマークアップし、行に分けた短文は `<span class="seg">`（block）にする。行末の句読点は省く。`word-break: keep-all` と `overflow-wrap: anywhere` の併記はしない。1440 / 834 / 390px で検証する。

v2 で CSS は index.html 内に同梱した（単一HTML完結）。style.css は同梱化の案内のみを残す。アンカーID（target / program / format / lecturer / apply / notes）とフォーム項目・無効化した送信ボタンは v1 のまま維持する。
