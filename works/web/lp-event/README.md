# P06 イベント集客LP「中小店舗のためのInstagram集客講座」（自主制作サンプル）

中小店舗向けオンライン講座（架空）の申込用ランディングページです。

## 見かた

- `index.html` をブラウザで開くと表示できます（Google Fonts を読むためネット接続が必要です）
- 公開URL（GitHub Pages 想定・未公開）：https://harugreed.github.io/coconala-portfolio/works/web/lp-event/
- 画面写真：`screenshots/`

## 構成

開催概要（日時・形式・参加費・定員・締切を入場券の形で）→ 対象 → 内容（時間割）→ 参加のしかた → 講師 → 申込フォーム → 注意事項

## 実案件で差し替える箇所

- 申込フォーム：送信ボタンを無効にしています。実案件では Peatix などの申込ページへのリンク、またはフォーム送信サービスに接続します
- 講師：架空の講師のため顔写真を置かず頭文字の印にしています。実案件では講師本人の写真に差し替えます
