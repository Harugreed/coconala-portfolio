# デザイン仕様：介護タクシー あおば移送サービス（架空・自主制作サンプル）v2

通院・買い物の外出を車いすのまま送迎する介護タクシー（架空）の申込用LP。目的は「料金と条件の理解 → 申込」。
制作ルールは `../../../WEB_RULES.md` と共通ブリーフ（portfolio-v2-brief）に従う。事実・料金・リンクは v1 から引き継ぐ。

## 参照プールから選んだ種（2026-11-26 確認）

| 種にした作例 | 出典 | なぜ題材に合うか・借りる技法 |
|---|---|---|
| 「Beauty Studio」 | MotionSites（motionsites.ai） | 地域のサービス業のLP作例。写真のヒーローで人のいる現場を見せ、その下に料金のあるサービスメニューを罫線の行で並べ、行動は1つに絞る構成が、介護タクシーの「現場の写真 → 料金表 → 申込」という流れと一致する。借りるのは構成（写真ヒーロー／料金メニューの行／単一の導線）だけで、配色と文章は題材自身から導く |
| Medical カテゴリの指針 | Landdding（landdding.com/c/medical） | 医療・ケア系LPは「具体性で決まる。実写真と単一の主要アクション、価格への明確な導線を持て」という同カテゴリの編集指針。煽りではなく料金と条件の具体性で信頼を作る方針をここから取る |

導出：種の構成（写真 → 料金メニュー → 単一導線）に、ケア系LPの具体性（運賃・介助・機材の3分法、合計の式、計算例）を重ね、運賃表の組版を骨格にする。文字は高齢の読み手向けに大きくし、数字は運賃メーター・駅の運賃表を思わせる細身の数字書体で組む。最終配色は題材の写真（hands.jpg のデニムと かばん）から導出する（下記）。

## コンセプト（1つ）

運賃表型LP。駅の運賃表や路線図のように、料金・エリア・予約期限という利用判断の事実を先に置き、文章は表と明細で読ませる。写真は care.jpg（公園の送迎）と hands.jpg（介助の手）の2枚だけを使う。

## Bold move（1つ）

ヒーロー右側に初乗り運賃「750」を Oswald 96px の特大数字で置き、その下に介助料・エリア・予約期限を運賃表の行として並べる。料金を装飾ではなくページの主役にする。

## 書体

- 数字・英字：Oswald（500・600）— 運賃メーターや駅の運賃表の細身の数字で、料金を「表」として読ませる
- 日本語見出し・本文：Noto Sans JP（500・700・900）
- 本文 18px（スマホ 17px相当）。高齢の読み手を想定し他作品より大きくする

## セクション順（骨格：運賃表→明細→手順の台帳）

1. ヘッダー（事業者名・予約電話 8:00〜18:00・番号は文字のみ）
2. ヒーロー：写真（横長・全幅）→ サービス名と1文 → 運賃表帯（特大750円＋介助料・エリア・予約期限の行）→ 申込導線
3. 利用場面と料金の計算例（通院・買い物の明細書式、合計を差し色で言い切る）
4. 予約から帰宅までの流れ（番号付き台帳の5行＋hands.jpg＋動画枠）
5. 料金（運賃・介助料・機材の3表を縦に積む）
6. よくある質問（開閉式6問）
7. 申込フォーム（送信ボタンは無効化したサンプルのまま）
8. フッター（許可番号・住所・電話・サンプルの明記）
スマホは画面下に「申込フォームへ」を固定する（v1の導線を維持）。

## 禁止要素（6つ）

1. 角丸カード＋影の量産と、均一な3列カードグリッド
2. 丸い番号バッジと縦の点線でつなぐ手順（v1の骨格の流用）
3. 紫〜青グラデーションのヒーロー
4. 絵文字の箇条書き・アイコン代用
5. 利用者の声・満足度・受注件数などの捏造指標と、煽り文句
6. 写真同士を重ねる配置と、写真キャプション

## 改行の実装

日本語の表示行は意味の塊ごとに `<span class="nb">`（nowrap）でマークアップし、行に分けた短文は `<span class="seg">`（block）にする。行末の句読点は省く。`word-break: keep-all` と `overflow-wrap: anywhere` の併記はしない。1440 / 834 / 390px で検証する。

## 技術メモ

v2 で CSS は index.html 内に同梱した（単一HTML完結）。style.css は同梱化の案内のみを残す。アンカーID（scene / flow / price / faq / apply）とフォーム項目・無効化した送信ボタンは v1 のまま維持する。
