# デザイン仕様：介護タクシー あおば移送サービス（架空・自主制作サンプル）

通院・買い物の外出を車いすのまま送迎する介護タクシー（架空）の申込用LP。目的は「使い方の理解 → 申込」。
制作ルールは `../../../WEB_RULES.md` に従う。

## 1. 参考にしたサイト・資料（2026-11-22 確認）

| サイト | URL | 読み取れた点 |
|---|---|---|
| 日本交通 | https://www.nihon-kotsu.co.jp/ | 本文に BIZ UDPゴシック・大きめの文字（約24px）を使う |

料金は上記の相場の範囲で架空に設定した。

## 2. 前回作との差

同じ種類（介護・送迎のLP）の前回作はない。本シリーズの他作品とは、角丸ゴシック・丸い番号・縦の点線でつないだ手順の骨格で差を付けた。

## 3. 配色（3色）と出所

| 役割 | HEX | 出所 |
|---|---|---|
| 地 | `#FFFFFF`（面の区切りに #EEF3F8） | 白。区切りの面は主色を薄くした色 |
| 主色 | `#2C5A88` | 車いすの利用者のデニム（hands.jpg の #577EAA）を、白地で読める濃さに暗くした色 |
| 申込の導線 | `#C24A35` | 利用者のかばんの赤（hands.jpg の #B75E50）を少し鮮やかにした色。申込ボタンと必須表示だけに使う |

## 4. 書体

- Zen Maru Gothic（500・700）。角の丸いゴシックで、高齢の利用者・家族が読みやすい太さにする
- 本文18px（スマホ17px）。高齢の読み手を想定して、他作品より2px大きくする

## 6. 余白の段階

8・16・24・40・64・104px。セクション上下 104px（スマホ 64px）。

## 7. レイアウトの型（不安を下げる順番）

```
最初の画面：写真（横長）→ 何のサービスか1文 → 運賃・介助料・エリア・予約期限 → 申込へ
1. よく使われている場面（通院・買い物）と料金の計算例
2. 予約から帰宅までの流れ（5手順）＋写真＋動画を後から入れる枠
3. 料金（運賃・介助料・機材の3表）
4. よくある質問（開閉式6問）
5. 申込フォーム
スマホは画面下に「申込フォームへ」を固定
```

先に「何をしてくれるか」「いくらかかるか」を見せ、流れ・質問で不安を解いてからフォームに進む順番にした。

## 8. 使わない要素

- 利用者の声・「満足度○%」・受注件数
- 実在しない電話リンク（電話番号は文字だけ）、送信できるように見えるフォーム（送信ボタンは無効化）
- 写真キャプション（動画枠の説明は差し替えの案内のため残す）
