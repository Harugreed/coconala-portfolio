# P05 サービス申込LP「介護タクシー あおば移送サービス」（自主制作サンプル）

通院・買い物の外出を送迎する介護タクシー（架空）の申込用ランディングページです。

## 見かた

- `index.html` をブラウザで開くと表示できます（Google Fonts を読むためネット接続が必要です）
- 公開URL（GitHub Pages 想定・未公開）：https://harugreed.github.io/coconala-portfolio/works/web/lp-service/
- 画面写真：`screenshots/`

## 構成（不安を下げる順番）

最初の画面（何のサービスか・運賃・介助料・エリア・予約期限）→ よく使われている場面と料金の計算例 → 予約から帰宅までの流れ（5手順）→ 料金表 → よくある質問 → 申込フォーム

## 実案件で差し替える箇所

- 動画の枠：「予約から帰宅までの流れ」の右側に、16:9の動画を入れる枠を用意しています。`.video-frame` の中に `<video>` または YouTube の埋め込みを入れます
- 申込フォーム：送信ボタンを無効にしています。実案件ではフォーム送信サービスを接続します
- 電話番号：架空のため文字だけにしています。実案件では `tel:` のリンクにします

## 応募時の紹介文（3行）

介護タクシーの申込を目的にしたランディングページの自主制作サンプルです。
場面ごとの料金の計算例・5手順の流れ・よくある質問の順に置き、初めての利用の不安を下げてからフォームへ進む構成です。
高齢の読み手を想定して本文を18pxにし、後から短い動画を差し込める枠を用意しています。
