よく使われている場面

通院

会計・薬の受け取りまで済ませてから、ご自宅へお送りします。

例：自宅 → あおば総合病院（片道5km・付き添い2時間）
運賃 往復 3,300円乗り降りの介助 4回 4,000円付き添い 2時間 4,000円
合計 11,300円

買い物

スーパー・ホームセンターでの買い物に同行し、荷物を車まで運びます。
購入した荷物は玄関の中までお運びします。

例：自宅 → 駅前のスーパー（片道3km・買い物1時間）
運賃 往復 2,100円乗り降りの介助 4回 4,000円付き添い 1時間 2,000円

予約から帰宅までの流れ

  1. 予約

    利用日の前日17:00までに、電話または申込フォームでお申し込みください
    行き先・時刻・車いすの有無を確認し、料金の目安をお伝えします

  2. お迎え

    予約時刻の5分前にご自宅へ伺います
    玄関の段差・2階までの階段は、介助者が車いすごと運びます

  3. 乗車

    後ろのスロープから車いすのまま乗車し、4か所のベルトで固定します
    付き添いの家族も2人まで同乗できます

  4. 付き添い

    病院内の受付・診察室への移動・会計・薬の受け取りに付き添います
    買い物では売り場の移動と荷物の運搬を手伝います

  5. 帰宅

    ご自宅の室内まで車いすを押してお送りします
    料金はその場で現金または交通系ICでお支払いください

よくある質問

車いすを持っていなくても利用できますか

利用できます。普通型の車いすは無料でお貸ししています。予約時にお申し付けください。

家族は一緒に乗れますか

付き添いの方は2人まで同乗できます。同乗の料金はかかりません。

当日の予約はできますか

空きがあれば受け付けます。8:00以降にお電話でお問い合わせください。

病院の待ち時間が長くなった場合はどうなりますか

付き添いの料金が30分ごとに1,000円加わります。待ち時間中に一度ご自宅へ戻ることもできます。

キャンセル料はかかりますか

前日17:00までは無料です。当日のキャンセルは迎車料として1,000円を頂いています。

支払い方法を教えてください

降車時に現金または交通系ICでお支払いください。月ごとの請求書払いは、2回目の利用からご相談ください。
