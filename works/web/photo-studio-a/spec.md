# 穂波写真室（制作サンプル・A案）— デザイン仕様

案件：ココナラ 5396242（フィルト／写真スタジオのSTUDIOサイト制作）向け案件専用サンプル
位置づけ：方向性の異なる3案（A・B・C）からクライアントに選んでもらうための1案。本案は A案「光で現像するギャラリー」。

## コンセプト
窓から入る自然光そのものをページの仕掛けにする。暗い茶の画面に琥珀色の柔らかい光が差し、光が当たった写真だけが色づいて浮かび上がる。「撮影は窓から入る自然光を基本にしています」というスタジオの設定を、文章ではなくページの動きで示す。情報セクション（料金・運営者・アクセス・予約）は温かい白の地に置き、暗さの中でも読みやすさを保つ。

## デザインの種・参照した技法
- Haru が MotionSites／60fps 系から探したギミック候補3案のうちの A案で制作
- MotionSites 公式スキル（Motionsites-AI/claude-skill）の技法レシピ「spotlight reveals」の発想を参照：radial-gradient のスポットライトで対象を照らし出す見せ方を、写真スタジオの自然光に読み替えた
- 実装は独自に書いた：写真の上に琥珀のグロー層と暗転ベールを重ね、ベールの中心（光の位置）を CSS 変数 --sx / --sy で動かす。ポインタに追随し、タッチ端末とポインタ静止時は光が自動でゆっくり移動する（ゾーンごとに位相をずらしたリサージュ運動）。prefers-reduced-motion では光を中央に固定し、ベールを薄くして写真が見える状態にする
- 素材・文章・コードのコピーはしていない

## 配色（3色）
- 地（暗部）：#211509（暗い茶。ヒーロー、ギャラリー、フッター）
- 地（明部）：#F6EDDC（温かい白。スタジオについて、料金、運営者、アクセス、予約）
- 差し色：#CE9131（琥珀。光のグロー、ラベルの罫、フッターの料金だけに使う）
- 補助：文字の濃淡と罫線は上記3色の濃淡で作る（暗部文字 #F3E9D7／暗部補助 #B8A888／明部文字 #33241A／明部補助 #77644C／罫線 #4A3823・#DCC7A2）
- 色の出所：古民家の木部と窓から差す夕方の光から拾った茶と琥珀（写真スタジオ自身の要素）

## 書体（タイポグラフィ設計）
書体の格を役割で分ける。主役は大きく、脇は小さく静かに。
- 表示（店名・見出し・プラン名・運営者名）：Shippori Mincho（600）。品のある明朝で運び、字間は .18em と広めに取る
- 本文：Zen Kaku Gothic New（400）。行間 2.0、字間 .05em で、暗い画面でも読み疲れしない読みやすいゴシック
- 英字ラベル（ABOUT／PLANS 等）：Shippori Mincho の欧文。字間 .42em まで広げた小さなキャピタルで、静かな格を作る（書体は2種に抑え、格の差は役割と字間で作る）
- 料金の数字：Shippori Mincho の欧文数字 ＋ tabular-nums で大きく見せる（21px）。フッターの料金一覧も同じ扱い
- アクセス表などの数字：tabular-nums で桁を揃える
- 対比の原則：ヒーロー店名だけを突出させ（最大84px）、所在地などの脇役は 12px・字間 .22em・ウェイト300で静かに置く

## 文字・余白の段階
- ヒーロー店名：clamp(48px, 7.5vw, 84px)（SP 34px）／h2：22px／本文：15px（行間2.0）／小：12〜13px／ラベル：11px（字間.42em）／料金数字：21px
- セクション余白：128px（834px以下 96px、560px以下 80px）、間隔は8の倍数で統一

## 骨格
細いヘッダー（暗部）→ ヒーロー（全面写真＋スポットライト＋左下に店名と所在地）→ スタジオについて（明部：細幅の本文＋全幅写真＋事実の帯）→ 罫線の料金表（明部）→ ギャラリー（暗部：スポットライト＋大5点の可変グリッド）→ 運営者（明部：写真と経歴リスト）→ アクセス表＋外観写真（明部）→ 予約（明部：罫線ボタン）→ フッター（暗部：プラン名＋料金の一覧）
（C案＝生成り地にフィルムの帯＋縦書き、B案＝カーソルを追う写真カード、と骨格・配色・主役の装置を変えている）

## スポットライトの仕様
- 対象ゾーン：ヒーローとギャラリーの2か所のみ。情報セクションには入れない
- ギャラリーではベールとグローを写真グリッドの内側にだけ重ね、見出しは光の外でも読める状態を保つ
- 光の半径：ヒーロー 430px（834px以下 300px、560px以下 210px）／ギャラリー 320px（同 240px／170px）
- 光の外側はベール（暗い茶、最大 .88）で落とし、光の内側だけ写真が本来の色と明るさで見える。グローは琥珀 rgba(224,164,65,.34) を中心に重ねる
- 操作：ポインタ追随（タッチのポインタは無視）。ポインタが離れる、または6秒動かないと自動移動に復帰。タッチ端末では最初から自動移動
- 写真キャプションは付けない（光は装置であり、写真の説明ではない）

## 禁止要素
角丸カード＋影の量産、中央揃え均一グリッド、写真キャプション、キャッチコピー、紫〜青グラデーション、冷たいモノクローム、全面を暗くして情報を読みにくくすること
