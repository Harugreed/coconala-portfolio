# 穂波写真室（制作サンプル）— デザイン仕様

案件：ココナラ 5396242（フィルト／写真スタジオのSTUDIOサイト制作）向け案件専用サンプル

## コンセプト
写真だけが並ぶ、ギャラリーの白い壁。文章のヒーローは置かず、開いた瞬間から大きな写真のインデックスが始まる。文字は小さく静かに添え、余白と写真そのもので運ぶ1ページ。

## デザインの種
Godly 掲載「Ruben Wyttenbach Photography」（スイス・ベルンのフォトグラファー Ruben Wyttenbach のポートフォリオサイト、https://rubenwyttenbach.ch）
- ライブラリ内の位置づけ：Godly のタイプ別フィルタ「Photography」（https://godly.website/?types=%5B%22photography%22%5D ）に掲載される唯一の作例として確認（2026-11-26 実地確認）
- 実際に開いて確認した設計：
  - ヒーロー文案なし。トップは小さなモノグラムと名前だけの細いヘッダーで、直下から大きな写真がグリッド状に続く「インデックス」そのものがトップ画面
  - 写真は大きさに変化のあるグリッドで並び、ページ全体が展示壁のように白い余白で組まれる
  - タイポグラフィは終始小さく静か（名前・カテゴリ名程度）。大きな見出しで運ばない
  - フッターはカテゴリのインデックス（Editorial 17／Artwork 7／Commercial 6 のように件数付きの一覧）で締める
  - 色は白と黒のモノクローム基調で、色は写真の中にだけある
- 借りた具体的な設計：①文案ヒーローを廃し、写真インデックスからページを始める構成 ②大きさの違う写真を余白のあるグリッドで並べる展示壁の見せ方 ③文字を小さく静かに保つタイポグラフィ ④フッターをプランのインデックス（一覧＋料金）で締める型
- Haruルール優先で変えた点：種では各写真に題名とカテゴリのラベルが付くが、写真キャプション・ラベル禁止（文体ルール7）に従いラベルは付けない。カテゴリ情報は料金表に集約した。フッターの件数表示は当サイトに該当する数え方がないため、件数の代わりに料金を添えた
- 素材・文章・コードのコピーはしていない

### 種の選定経緯（2026-11-26）
- 第一候補 MotionSites を確認：写真ジャンルの作例は「Photo Globe」（写真タイルの球体ギャラリー）のみで、プロンプト全文はアカウント登録後の限定公開のため取得できず、かつ球体3Dの仕掛けは地域の家族向けスタジオの信頼感と合わないため不採用
- GoodCase の「AI Photography Studio Booking Website」は MotionSites 作例ではなく一般投稿のプロンプトで、設計情報を持たないため不採用
- 次点 Godly の Photography フィルタで唯一掲載の本作例を採用（フォトグラファー本人の実サイトを実際に開いて確認済み）

## 配色（モノクローム3色＋罫線）
- 地：#FFFFFF（ギャラリーの白。種の展示壁から）
- 文字：#161513（墨に近い黒）
- 補助：#6E6A63（温かみのあるグレー。小さいラベルと注記用）
- 罫線：#E5E2DB
- 強調色は置かない。色は写真の中にだけ置く

## 書体
- 全て Zen Kaku Gothic New（300／400／500）。明朝は使わない（種のニュートラルなグロテスクに合わせ、前回の明朝見出し版と書体から変えた）

## 文字・余白の段階
- 店名：30px／h2：19px／本文：14.5px（行間2.0）／小：12.5px／ラベル：11px（字間.32em）
- セクション余白：144px（SP 80px）、間隔は8の倍数で統一

## 骨格
細いヘッダー → 店名と所在地の小さなタイトル行 → 写真インデックス（大4点、幅7:5と5:7の交互）→ 細幅の本文＋全幅写真＋事実の帯 → 罫線の料金表 → 写真インデックスの続き（3点、全幅1点を含む）→ 運営者（写真と経歴リスト）→ アクセス表＋外観写真 → 予約（白地に罫線ボタン）→ インデックス型フッター
（前回の全面写真ヒーロー＋明朝版、ジム＝数字主役の青、サロン＝1カラム料金表型と骨格・配色・書体を変えている）

## モーション
冒頭の写真インデックスだけ、読み込み時に緩やかなフェードとスケール（1.6s、0.15s刻みのずらし）。他のセクションには入れない。prefers-reduced-motion では無効化

## 禁止要素
角丸カード＋影の量産、中央揃え均一グリッド、写真キャプション・ラベル、キャッチコピー、紫〜青グラデーション、全面写真ヒーロー＋大きな店名の重ね書き
