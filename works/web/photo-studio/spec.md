# 穂波写真室（制作サンプル）— デザイン仕様

案件：ココナラ 5396242（フィルト／写真スタジオのSTUDIOサイト制作）向け案件専用サンプル

## コンセプト
古い空き家に差す自然光を主役にした、写真で語る1ページ。全面写真のヒーローに店名を大きく置き、本文は細い罫線と広い余白で静かに組む。

## デザインの種
Landdding「Studio Sandcastle」（sandcastle.studio／Landdding掲載、パレット #94846C Beige）
- 借りた技法：温かいベージュの地、2〜3色に抑えた配色、大きなセリフ体で運ぶ見出し、余白で写真を囲む構成、控えめなモーション
- 素材・文章・コードのコピーはしていない

## 配色（3色＋同色相の濃淡）
- 地：#F8F4EC（温かい白）
- 文字：#43382B（茶を含む黒）
- 主色：#94846C（ヌードベージュ。種のパレットと募集文の希望色から）
- 濃ベージュ：#6E5F49（小さいラベル用）、帯：#EFE8DA、罫線：#DCD2BE

## 書体
- 見出し：Shippori Mincho（明朝）
- 本文：Zen Kaku Gothic New（細め）
- 英字ラベル：Zen Kaku Gothic New、字間広め

## 文字・余白の段階
- ヒーロー店名：clamp(46px, 8vw, 84px)／h2：28px／リード：17px／本文：15px（行間2.0）／小：12.5px
- セクション余白：144px（SP 80px）、段落間は8の倍数で統一

## 骨格
全面写真ヒーロー（下部に店名）→ 細幅の本文＋全幅写真 → 罫線の料金表 → 写真だけのギャラリー → 経歴リスト → アクセス表＋外観写真 → 予約帯 → フッター
（ジム＝数字主役の青、サロン＝1カラム料金表型、カフェ＝編集型と骨格・配色を変えている）

## モーション
ヒーロー写真の緩やかなスケール（2.4s）のみ。他は入れない。

## 禁止要素
角丸カード＋影の量産、中央揃え均一グリッド、写真キャプション、キャッチコピー、紫〜青グラデーション
