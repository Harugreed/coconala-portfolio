# 穂波写真室（制作サンプル）— デザイン仕様

案件：ココナラ 5396242（フィルト／写真スタジオのSTUDIOサイト制作）向け案件専用サンプル

## コンセプト
流れるフィルムと、写真に立つ縦書きの店名。看板装置は2つだけに絞る：写真をコマ枠に入れて流し続ける「フィルムの帯」と、ヒーロー写真の上に大きく立つ縦書きの「穂波写真室」。地は温かい生成りで組み、本文は罫線と余白で静かに運ぶ。

## デザインの種・参照した技法
- Haru が選定した C案（フィルムの帯＋縦書き）で制作
- MotionSites 公式スキル（Motionsites-AI/claude-skill）の技法レシピ群を参照：seamless loop（継ぎ目のない無限ループ）の作法でフィルムの帯を実装（同一セットを2つ並べ、-50%でループさせる方式）
- 60fps.design 系のモーション作法を参照：動きはゆっくり・一定速度・控えめに。帯の速度は1本目55秒/周、2本目68秒/周（逆方向）。ホバーで一時停止。スクロール連動の演出や各セクションへの出現アニメーションは入れない
- ヒーローの入場だけ、写真と縦書きに緩やかなフェード＋スケール（1.6s）を許可。prefers-reduced-motion では全モーション無効化
- 素材・文章・コードのコピーはしていない

### 作り直しの経緯（2026-11-26）
- 初版：ベージュ地＋全面写真ヒーローに明朝の店名を重ねる型。Haru から「種にした作例の確認が浅い」と指摘
- 2版：Godly 掲載のフォトグラファー作例を種に、モノクロームの展示壁＋写真インデックス型に作り直し。Haru 評価「スタイリッシュさと温かみがなく、頭ひとつ抜けていない」で却下
- 3版（現行）：Haru が MotionSites／60fps 系から探したギミック候補3案（A：光で現像するギャラリー／B：カーソルを追う写真カード／C：フィルムの帯＋縦書き）から C を選択。温かみのある生成り地に戻し、看板装置をフィルム帯と縦書きに絞った

## 配色（生成り＋茶系の墨＋琥珀1色、フィルム帯は焦げ茶）
- 地：#FAF5EA（温かい生成り）
- 文字：#3B2E23（茶を含む墨）
- 補助：#6F5D47（小さいラベルと注記用）
- 差し色：#B07C24（琥珀。ラベルの罫とフッターの料金だけに使う）
- 罫線：#E2D5BF
- フィルム帯：#2A2019（焦げ茶）、コマ枠：#453322、パーフォレーションは地色の円で抜く
- 色の出所：フィルムの現像・印画紙と古民家の木部から拾った茶系で統一（写真スタジオ自身の要素）

## 書体
- 表示：Shippori Mincho（縦書きの店名、見出し、ロゴ）
- 本文：Zen Kaku Gothic New（300／400／500）

## 文字・余白の段階
- 縦書き店名：clamp(64px, 10vw, 112px)（SP 32px）／h2：20px／本文：15px（行間1.9）／小：12〜13px／ラベル：11px（字間.32em）
- セクション余白：128px（834px以下 96px、560px以下 80px）、間隔は8の倍数で統一

## 骨格
細いヘッダー → ヒーロー（全面写真＋右に縦書きの店名＋左下に所在地の小さい横書き）→ フィルムの帯1（家族写真・七五三・ウェディング・赤ちゃん・成人式）→ スタジオについて（細幅の本文＋全幅写真＋事実の帯）→ 罫線の料金表 → ギャラリー（大3点）→ フィルムの帯2（装花・内部・外観・運営者・和室、逆方向）→ 運営者（写真と経歴リスト）→ アクセス表＋外観写真 → 予約（生成り地に罫線ボタン）→ フッター（プラン名＋料金の一覧）
（2版＝モノクローム展示壁の写真インデックス型、初版＝ベージュ＋全面写真ヒーローに横書きの店名を重ねる型、と骨格・配色・主役の装置を変えている）

## フィルムの帯の仕様
- 帯の上下にパーフォレーション（穴の列）を地色の円で抜き、写真は焦げ茶のコマ枠（枠6px）に入れる
- 写真は同梱の実写を再利用。コマの高さは200px（834px以下 160px、560px以下 128px）
- コマの下に説明文は付けない（フィルムのコマ枠は装置であり、写真キャプションではない）

## 禁止要素
角丸カード＋影の量産、中央揃え均一グリッド、写真キャプション、キャッチコピー、紫〜青グラデーション、冷たいモノクローム、スクロール連動の派手な演出
