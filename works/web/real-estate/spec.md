# すみか不動産（制作サンプル）— デザイン仕様

案件：ココナラ 5397397（マイティーモー／不動産会社のHP制作）向け案件専用サンプル。全7ページ構成のうち、トップページ1枚に各セクションを凝縮して見せる形。

## コンセプト
白っぽい明るい地の上に、大きなセリフの言い切り見出しと物件写真の帯で「地域で信頼される不動産会社」を最初の画面で言い切る1ページ。装置はロード画面と成果セクションの数字アニメーションの2つに絞り、本文は静かに組む。

## デザインの種：Caso Patrimoine（主体）＋ Blue Yonder Property Group（成果セクションのみ）
- Caso Patrimoine（https://www.caso-patrimoine.fr/、フランス・トゥールーズ発祥の家族経営不動産会社、Landbook Real Estate掲載）から借りた文法：
  - 明るいオフホワイトの地＋温かい茶・ベージュの差し色、大きなセリフ見出し＋サンセリフ本文
  - ヒーロー：「信頼＋地名」を言い切る巨大セリフ見出しの下に、物件写真5枚を横一列の帯で並べる（帯は画面端で切れる構図、写真は小さな角丸）
  - 価値観・事業を番号付き（01〜04）で並べる反復構成
  - 代表者の写真＋理念の引用、保有物件のグリッド、お知らせへ続く流れ
- Blue Yonder Property Group（https://www.bypg.com/、米オースティンの不動産会社）から成果セクションだけ借りた文法：
  - 大きなセリフ数字がスクロールでカウントアップ＋スライドインして現れ、数字の反復で実績を押し切る構成
  - 本家の赤＋ピンクは使わず、白基調＋茶系（濃茶 #542F1C）に落とした
- 素材・文章・コードのコピーはしていない。クライアント本人の指定「白っぽい明るい雰囲気」に合わせ、地は Caso のオフホワイトをさらに明るく保った
- 選定経緯：Haru が候補4件（Caso／September／Blue Yonder／Huts）から「全体は1位 Caso、成果の動きだけ3位 Blue Yonder」を指示（2026-11-26）

## ロード画面の仕様
- ページを開いた最初に、オフホワイトの地のロード画面を全画面で表示する
- 中央に仮のロゴ置き場：細い罫（1px）の枠の中に小さい英字「LOGO」と「ロゴをここに入れます」の文字。その下にダミー社名「すみか不動産」をセリフで置く
- 枠の下に差し色の細いバー（120px）が1.6秒かけて伸びる。表示は約1.9秒でフェードアウト（0.8秒）してヒーローへ渡す
- クリック／タップで即座に消える。prefers-reduced-motion では表示せず本編を即時表示。JS無効時の保険として CSS アニメーションで4.5秒後に自動で消える
- 受け渡しと連動して、ヒーロー見出しの行と写真の帯が時間差で静かに上がる（開いた時のアニメーションの舞台）

## 配色（オフホワイト＋温かい茶）
- 地：#EEE9E7（Caso のオフホワイト）
- 面：#FFFFFF（会社概要・お知らせ等の情報セクションで使う白）
- 文字：#2B2320（温かい墨）
- 補助：#6B5847（ラベルと注記用）
- 差し色：#71563A（温かい茶を濃くした色。番号、ラベルの四角、ロード画面のバー、成約済タグの罫）
- 濃色：#542F1C（深い茶。巨大数字、見出しの強調、成約済タグの地）
- 罫線：#DCD2C4
- 色の出所：同梱実写の木部・石壁の茶（hero-2.jpg の石と木、hero-3.jpg のキッチン木目）から拾った茶系2色に、地のオフホワイトを合わせた

## 書体（2書体・役割で格分け）
- Zen Old Mincho＝表示の顔：社名ロゴ、ヒーロー見出し、セクション見出し、理念の引用、代表者名、実績の巨大数字、物件価格、電話番号。数字は tabular-nums
- Zen Kaku Gothic New（300／400／500）＝本文と情報：本文、表の情報セル、注記、お知らせ。英字ラベルは字間.42em、差し色の小さな四角と組で格を出す

## 文字・余白の段階
- ヒーロー見出し：clamp(38px, 6.2vw, 80px)・字間.06em／ロゴ：20px／h2：clamp(24px, 2.6vw, 30px)・字間.12em／実績数字：clamp(56px, 7.5vw, 96px)／物件価格：22px／本文：15px（行間1.9、字間.05em）／小：12〜14px／ラベル：12px（字間.42em）
- セクション余白：128px（834px以下 96px、560px以下 80px）、間隔は4の倍数で統一

## 骨格
ロード画面 → ヘッダー（セリフの社名ロゴ＋ナビ、お問い合わせだけ罫の枠ボタン）→ ヒーロー（巨大セリフ見出し＋短い案内文＋物件写真5枚の帯）→ 理念・代表挨拶（代表写真と引用の2カラム）→ 事業内容（番号付き01〜04の罫線リスト）→ 成約実績（巨大数字3点のカウントアップ＋物件グリッド4点）→ お知らせ（日付と本文の罫線リスト）→ 会社概要（白面の表）→ 公式LINE・お問い合わせ（QR仮置き枠と電話番号大表示の2カラム）→ フッター
（写真スタジオE案＝スライドショー＋生成り＋エンジ、ジム第2案＝ベージュ＋巨大ワードマーク、と地・主色・骨格の3点で重ならない）

## 成果セクションのアニメーション仕様
- 実績数字3点（成約件数128件／取扱物件数342件／ご相談件数516件）は IntersectionObserver で画面に入った時に発火し、約1.4秒かけて 0 からカウントアップする。同時に各ブロックが translateY(24px)＋透明から時間差（0／120／240ms）でスライドインする
- 数字は Zen Old Mincho の tabular-nums で組み、単位（件）は小さく添える
- prefers-reduced-motion ではアニメーションせず最終値を即時表示する

- 社名「すみか不動産株式会社」、代表者「山田 太郎」、地名は「○○市」で統一
- 住所：○○県○○市○○町1-2-3（郵便番号 000-0000）、電話：000-0000-0000、免許番号：○○県知事（1）第00000号
- 物件情報（エリア・種別・価格・間取り・面積）と実績数値（128件・342件・516件）はダミーの一例とし、該当箇所の近くに小さい注記（※実績の数値はダミーの一例です／※物件情報はダミーです）を入れた
- お知らせの日付と本文、会社概要の設立年等もダミー
- フッターに「このページは制作サンプルです。社名、住所、電話番号、物件情報、実績数値など、掲載している情報はすべてダミーです。お問い合わせと公式LINEのリンクは省略しています。」を明記
- ロゴと公式LINEのQRコードは、本制作でクライアントから支給される前提で「ここに入れます／ここに配置します」の仮置き枠にした
