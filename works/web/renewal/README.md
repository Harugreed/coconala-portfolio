## 見かた

- `index.html`：3点への入口（Before・After・提案書）
- 公開URL（GitHub Pages 想定・未公開）：https://harugreed.github.io/coconala-portfolio/works/web/renewal/

| パス | 内容 |

## 応募時の紹介文（3行）

老舗和菓子店を想定したホームページのリニューアル提案セット（自主制作サンプル）です。
古いページの問題点を7項目に整理し、同じ情報でスマートフォン対応のページに作り直したBefore／Afterを用意しています。
改善内容・制作の流れ・料金をA4・2ページの提案書（PDF付き）にまとめています。
