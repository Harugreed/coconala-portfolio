# デザイン仕様：白杢珈琲（架空・自主制作サンプル）第2版

郊外の焙煎所兼カフェ（架空）。店内の5kg焙煎機で焙煎した豆を使い、ドリップコーヒー・焼き菓子を出す。
制作ルールは `../../../WEB_RULES.md`（Haru指定）に従う。

他のカフェ系（igafe：ミント・琥珀、cafe-off：紺・ワイン、lucelato：淡青・紺）とも地・主色が重ならない。

## 4. 書体

- 明朝（飲食のアクセント）：Shippori Mincho B1（500・700）。店名・見出し・価格・数字
- ゴシック（本文）：Zen Kaku Gothic New（400・500）
- 英字の大文字ラベルは使わない

## 6. 余白の段階

8px を単位に 8・16・24・40・64・104・144px の7段階。セクション上下 144px（スマホ 88px）、見出しと本文 40px（スマホ 24px）、品目の間 24px。本文幅は最大 1120px。

## 7. レイアウトの型

```
┌────────────────────────────────────────┐
│ 印＋店名(小)                メニュー 豆 店内 アクセス │
├────────────────────────────────────────┤
│ 案内表（罫線4行）                       白 │ ← 店名は縦書きで右端
│  営業時間 8:00〜17:00                   杢 │   背後に印の杢目を拡大した線
│  定休日   火曜・第3水曜                 珈 │
│  所在地   …駅南口から徒歩6分             琲 │
│  駐車場   3台                              │
│ 店の説明（2行）                            │
├────────────────────────────────────────┤
│ 写真1 焙煎機（横長・全幅の帯 2.6:1）        │
├────────────────────────────────────────┤
│ メニュー：コーヒー │ 焼き菓子（2段組・罫線）  │
│ 豆の販売：写真2（横長）│ 価格表             │
│ 店内：設備の表（2段組）                     │
│ アクセス：略地図 │ 道順・営業案内           │
└────────────────────────────────────────┘
```

- 左揃えを基本にし、中央揃えは使わない
- 写真は横長2枚だけ。キャプションは付けず、写真同士を重ねない
- 文様：ロゴの印に描いた杢目（木目の同心曲線）を拡大し、トップの背景に薄く敷く。他の装飾は足さない

## 8. 使わない要素

- お客様の声・星評価・受注件数・キャッチコピー・写真キャプション
- 英字の大文字ラベル、01/02 の番号飾り、スクロールのたびに出るフェード
- 角丸カード＋影の量産、中央揃えの均一グリッド、絵文字
- 季節・月替わりの情報、日付入りのカレンダー
- 実在しないリンクやボタン（予約フォーム・SNSボタン）

- 最初の画面で店名・営業時間・定休日・所在地が読める
- 価格・営業時間の行が単語の途中で折り返さない
