# P01 カフェの店舗HP「白杢珈琲」（自主制作サンプル）

郊外の焙煎所兼カフェ（架空）の1ページHPです。

## 見かた

- `index.html` をブラウザで開くと表示できます（Google Fonts を読むためネット接続が必要です）
- 公開URL（GitHub Pages 想定・未公開）：https://harugreed.github.io/coconala-portfolio/works/web/shop-cafe/
- 画面写真：`screenshots/pc-top.png`、`screenshots/sp-top.png`、`screenshots/pc-full.png`

## ファイル

| ファイル | 内容 |
|---|---|
| index.html | ページ本体（ナビ開閉の小さなスクリプトを含む） |
| style.css | スタイル |
| img/ | 写真2枚（Unsplash） |
| DESIGN.md | デザイン仕様（参考サイト5件・配色の出所・書体・余白・禁止事項） |
| credits.md | 写真の出典とライセンス |

## 構成

トップ（店名・営業時間・定休日・所在地・駐車場）→ 焙煎機の写真 → メニュー（コーヒー・焼き菓子）→ 豆の販売 → 店内 → アクセス・営業案内

## 応募時の紹介文（3行）

郊外の焙煎所兼カフェを想定した店舗HPの自主制作サンプルです。
配色は焙煎機・煎った豆の写真から3色を拾い、店名は明朝の縦書きにしています。
営業時間・定休日・所在地・駐車場を最初の画面に置き、スマホ幅375pxでも崩れない作りです。
