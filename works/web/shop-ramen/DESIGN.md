# デザイン仕様：らぁめん 雷紋堂（架空・自主制作サンプル）

駅前のカウンター10席の醤油豚骨ラーメン店（架空）。食券制。
制作ルールは `../../../WEB_RULES.md` に従う。

## 1. 参考にした同業種サイト（2026-11-22 確認）

| サイト | URL | 読み取れた点 |
|---|---|---|
| 一風堂 | https://www.ippudo.com/ | 丼の写真を大きく、商品名を太く大きく出す |
| 一蘭 | https://ichiran.com/ | 注文の流れ（食券→記入→提供）を手順で説明する |
| 天下一品 | https://www.tenkaippin.co.jp/ | 看板色を地に使い、文字を詰めて熱量を出す |
| AFURI | https://afuri.com/ | ロゴの書体をそのまま看板として大きく使う |
| 幸楽苑 | https://www.kourakuen.co.jp/ | 白地に商品写真と価格を大きく並べる |

5件ともブラウザで開き、表示とページタイトルを確認した（天下一品の地色は #E9E9E9）。とみ田・町田商店は自動アクセスを拒否されたため候補から外した。

カフェ（P01）の抜け感は使わない。余白を詰め、色を濃くし、品名と価格を大きく太くする。

## 3. 配色（3色）と出所

| 役割 | HEX | 出所 |
|---|---|---|
| 地 | `#F2A524` | 丼のスープと麺の金色（bowl.jpg の #F0A630） |
| 主色 | `#133C78` | 丼の縁の雷紋の藍（bowl.jpg の #0560B6）を、地の上で読める濃さまで暗くした色 |
| 価格 | `#C8161D` | プロンプト指定（価格は赤）。白い食券の上だけに置き、コントラスト比5.9を確保 |

食券の白（#FFFFFF）は券売機のボタンの色として使う。

## 4. 書体

- 見出し・店名・品名：Zen Old Mincho（900）。看板文字の太さを出す
- 本文・価格：M PLUS 1p（500・800）。価格は800で大きく
- カフェ（Shippori Mincho B1・Zen Kaku Gothic New）とは別の組み合わせ

## 6. 余白の段階

4px 単位で 4・8・12・20・32・56px。セクション上下 56px（スマホ 40px）。カフェの144pxの3分の1強に詰める。

## 7. レイアウトの型

```
┌ 藍の帯：店名(小)・営業時間・定休日 ───────────────┐
│ 金の地：店名を極太明朝で大きく／案内3項目を横並び      │
├ 雷紋の帯（丼の縁から） ─────────────────────────┤
│ 丼の写真（横長・全幅）                              │
├ 雷紋の帯 ───────────────────────────────────┤
│ 食券：主力2枚は大、ほかは中・小。左揃えで大きさを変える │
│ 注文の流れ：1→4（実際の手順）＋厨房の写真            │
│ 店舗情報（藍の地・白文字）                           │
└────────────────────────────────────────┘
```

## 8. 使わない要素

- 和紙・墨・赤の組み合わせ（前回作）、抜けた余白
- お客様の声・ランキング・「行列必至」などの文句、写真キャプション
- 角丸＋影のカード（食券は角を立て、影の代わりに藍の太線で縁取る）
- 季節限定メニュー、実在しないリンク
