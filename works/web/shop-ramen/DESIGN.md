# デザイン仕様：らぁめん 雷紋堂（架空・自主制作サンプル）v2

駅前のカウンター10席の醤油豚骨ラーメン店（架空）。食券制。
制作ルールは `../../../WEB_RULES.md` と共通ブリーフ（portfolio-v2-brief）に従う。
事実（店名・メニュー・価格・営業時間・住所等）は v1 からそのまま引き継ぐ。追加した事実はない。

## 参照プールの作例（主参照）

**「Kaedama: Ramen Bar Website Prompt」**（MotionSites 系のAIウェブサイトプロンプト集、websiteprompts.ai 掲載：https://websiteprompts.ai/prompts/ramen-bar）

なぜ合うか：カウンターだけの小さなラーメン店という題材が雷紋堂と一致し、「ポスターのように loud で packed なページ」という方向が、Haru指定の「暑苦しい熱量」と一致するため。借りる技法は構成とトークンの考え方だけ（素材・文章・コードはコピーしない）：

- 角丸ゼロ・太い罫線（作例は3pxの実線）で面を区切る → 食券の太線（藍4〜6px）に置き換える
- 丼を「tightly stacked rows（罫線で区切った帯の積み重ね）」で出す → メニューを食券の帯として縦に積む骨格に使う
- ボタンは「券売機のボタンのような大きなブロック」 → コンセプト「券売機の正面パネル」の直接の種
- 黄色いブロックは1か所だけ（作例は卵黄の黄） → メニュー面の金の帯1ブロックに絞る
- ヒーローはポスターとして全面に大きな活字 → 店名を96pxの極太明朝で全面に出す
- 色は作例のトマト赤＋クリームを借りず、題材自身の丼写真から金と藍を導出する（下記「配色」）

### 調査からの導出

- 品名と価格をページ最大級の活字にする（一風堂の「お品書き主役」から）。主力の価格は bold move として店名直下に置く
- 食券制という注文の仕組みを骨格にする（一蘭の「仕組みのコンテンツ化」から）。券売機の正面パネルをコンセプトにし、注文の流れを独立セクションにする
- 余白は密な档（セクション48px）にし、色は濃くする（天下一品の密度から）。カフェ的な抜け感は使わない
- 色は調査先の色を借りず、題材自身の丼写真（bowl.jpg）のスープの金と縁の雷紋の藍から取る

## コンセプト（1つ）

**券売機の正面パネル。** ページ全体を店頭の券売機の顔として組む。上部に店名と営業時間の表示窓、続いて主力商品の食券が1枚大きく出て、メニューはボタン式の食券の列として並ぶ。余白は詰め、色は濃く、品名と価格を大きく太く出す。カフェ的な抜け感は使わない。

## Bold move（1つ）

ヒーローの店名の直下に、主力の「醤油らぁめん 900円」を画面幅いっぱいの白い食券帯で出し、**価格を赤の80px（スマホ56px）で店名に次ぐ大きさに置く**。価格がページの第二の主役になる。

## 配色（3色）と出所

出所：丼の写真（img/bowl.jpg）のスープの金色と、丼の縁に描かれた雷紋の藍から拾った。価格の赤は券売機のボタンとメニュー短冊の赤字の色で、食券の白の上だけに置く。

| 役割 | HEX | 用途 |
|---|---|---|
| 主色 | `#133C78` | 丼の縁の雷紋の藍。ヘッダー・ヒーロー・店舗情報の地、食券の縁 |
| 地（メニュー面） | `#F2A524` | スープと麺の金色。メニュー帯の地 |
| 価格 | `#C8161D` | 券売機のボタンの赤。価格だけに使う |

食券の白 `#FFFFFF` は券売機のボタンの色として使う（色数に数えない面の色）。

## セクション順（骨格）

1. サンプル表記（白の細帯）
2. ヘッダー（藍地）：店名・営業時間・定休日・ページ内ナビ
3. ヒーロー（藍地）：店名を極太明朝で大きく、右に営業・定休・駅からの表示窓（罫線の表）
4. 主力の食券帯（白）：醤油らぁめん＋価格80px赤＋説明
5. 雷紋の帯 → 丼の写真（横長・全幅・彩度を上げて表示） → 雷紋の帯
6. メニュー（金の地）：食券を横長の帯として縦に積む（品名左・説明中・価格右）。主力2品は帯を太くする。トッピング・ご飯は2列の細い食券帯
7. 注文の流れ（白地）：4手順を番号の帯で積む＋厨房の写真を右に置く
8. 店舗情報（藍地・白文字）：2列の罫線表
9. フッター（藍地）：店名とサンプル表記

v1（金の地に食券カードのグリッド）とは地の置き方とメニューの骨格が違う。corporate（白地・公文書型）とも地・主色・骨格は重ならない。

## 改行の実装

日本語の表示行は意味の塊ごとに `<span class="nb">`（nowrap）でマークアップし、改行は塊の境目でのみ起こす。行単位の短文は `<span class="seg">`（block）。行に分けた短文は行末の句読点（。も、も）を省く。`word-break: keep-all` と `overflow-wrap: anywhere` の併記はしない。

## 禁止要素（6つ）

1. カフェ的な抜け感のある広い余白・中央揃えの均一グリッド
2. 角丸＋影のカード量産（食券は角を立て、藍の太線で縁取る）
3. 写真キャプション・キャッチコピー・タグライン
4. お客様の声・ランキング・「行列必至」などの誇張文句
5. 季節限定メニューなど日付で古くなる情報
6. 実在しない予約フォーム・ダミーのボタン・リンク
