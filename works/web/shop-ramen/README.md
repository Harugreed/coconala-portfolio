# P02 ラーメン店の店舗HP「らぁめん 雷紋堂」（自主制作サンプル）

駅前のカウンター10席・食券制のラーメン店（架空）の1ページHPです。

## 見かた

- `index.html` をブラウザで開くと表示できます（Google Fonts を読むためネット接続が必要です）
- 公開URL（GitHub Pages 想定・未公開）：https://harugreed.github.io/coconala-portfolio/works/web/shop-ramen/
- 画面写真：`screenshots/pc-top.png`、`screenshots/sp-top.png`、`screenshots/pc-full.png`

## ファイル

| ファイル | 内容 |
|---|---|
| index.html | ページ本体（CSS は同梱。雷紋の帯は CSS 内の SVG） |
| img/ | 写真2枚（Unsplash） |
| DESIGN.md | デザイン仕様（参考サイト5件・前回作との差・配色の出所・書体・余白） |
| credits.md | 写真の出典とライセンス |

## 構成

トップ（店名・営業時間・定休日・駅から）→ 主力の食券帯（醤油らぁめん 900円を大きく）→ 丼の写真 → メニュー（食券の帯を積む）→ 注文の流れ（4手順）→ 店舗情報

## 応募時の紹介文（3行）

駅前のラーメン店を想定した店舗HPの自主制作サンプルです。
スープの金色・丼の藍を配色に使い、メニューは券売機の食券の形で品名と価格を大きく出しています。
食券の買い方から丼の戻し方までを4手順で載せ、初めての来店者が迷わない作りにしています。
