# デザイン仕様：atelier GRIS（架空・自主制作サンプル）

住宅街の2階にある、ネイル2席・まつげ1台の予約制サロン（架空）。予約はLINE公式アカウントで受ける。
制作ルールは `../../../WEB_RULES.md` に従う。

## 2. 前回作との差

| 項目 | 前回のサロン系（YADORI・YOGMON） | 今回 |
|---|---|---|
| 地 | #F5F6F1（YADORI）・ピンク（YOGMON） | 店内の壁の白 #F6F7F8 |
| 主色 | 葉の緑・真鍮／ピンク | ジェルの青灰を暗くした #3F5563 |
| 骨格 | 1カラムの縦積み | PCは左に固定の目次列、右に本文が流れる2列 |

本シリーズのカフェ（縦書き店名）・ラーメン（食券の並び）とも骨格が異なる。

## 3. 配色（3色）と出所

| 役割 | HEX | 出所 |
|---|---|---|
| 地 | `#F6F7F8` | 受付の白い壁（room.jpg の #E8EBEE）を明るくした色 |
| 主色 | `#3F5563` | 爪のジェルの青灰（nails.jpg の #A6BDCA）を同じ色相のまま暗くした色 |
| 淡色（帯・罫線） | `#D5DFE5` | 同じジェルの色を明るくした色 |

3色とも同じ青灰の系統にまとめ、色数を増やさない。

## 4. 書体

- 和文：Zen Kaku Gothic Antique（300・400）。細めのゴシック
- 数字・欧文：Jost（300）
- 明朝は使わない（飲食2件との差）

## 5. 文字サイズの段階（PC／スマホ）

| 要素 | PC | スマホ |

| セクション見出し | 24px | 20px |
| 品名 | 15px | 14.5px |
| 価格 | 22px | 19px |

## 6. 余白の段階

8px 単位で 8・16・32・56・96・160px。セクション上下 160px（スマホ 96px）。目次列の幅 300px。

## 7. レイアウトの型

```
┌──────────┬──────────────────────────────┐
│ atelier  │ 爪の写真（横長 16:9）                    │
│ GRIS     │                                        │
│          │ メニューと料金（ネイル｜まつげ 2列）       │
│ メニュー  │ 施術の流れ（所要時間つき 4手順）          │
│ 流れ     │ 予約（LINE の手順・キャンセル規定）       │
│ 予約     │ 店舗情報＋受付の写真（横長）              │
│ 店舗     │                                        │
│ 営業時間  │                                        │
└──────────┴──────────────────────────────┘
```

- 左揃え。罫線は 1px の淡色だけで区切る
- 写真は横長2枚。キャプションなし

## 8. 使わない要素

- ピンク・金・花柄、筆記体のロゴ、キラキラした装飾
- お客様の声・指名数・「人気No.1」、写真キャプション
- 実在しないLINEボタン・予約フォーム（予約手順は文章で示す）
- 季節限定のデザイン紹介
