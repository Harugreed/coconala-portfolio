# P03 ネイル・まつげサロンの店舗HP「atelier GRIS」（自主制作サンプル）

ネイル2席・まつげ1台の予約制サロン（架空）の1ページHPです。

## 見かた

- `index.html` をブラウザで開くと表示できます（Google Fonts を読むためネット接続が必要です）
- 公開URL（GitHub Pages 想定・未公開）：https://harugreed.github.io/coconala-portfolio/works/web/shop-salon/
- 画面写真：`screenshots/pc-top.png`、`screenshots/sp-top.png`、`screenshots/pc-full.png`

## 構成

左の目次列（店名・営業時間・定休日・最寄り駅）／本文：写真 → メニューと料金 → 施術の流れ（所要時間つき）→ 予約（LINEの手順・キャンセル規定）→ 店舗情報

## 実案件で差し替える箇所

- LINE公式アカウントは架空のため、リンクとボタンを置いていません。実案件では「予約」の手順の横に友だち追加のリンクを置きます。

## 応募時の紹介文（3行）

ネイル・まつげの予約制サロンを想定した店舗HPの自主制作サンプルです。
配色はジェルの青灰1色の濃淡にまとめ、細いゴシックと広い余白で静かな印象にしています。
料金を言い切りで載せ、LINE予約の手順とキャンセル規定まで1ページで確認できる作りです。
