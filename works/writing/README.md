# P10 記事・文書サンプル一式（自主制作サンプル）

## 見かた

- `index.html` をブラウザで開くと一覧から各文書を読めます
- 各文書は `.html`（表示用）と `.md`（入稿用の原稿）の2形式です
- 公開URL（GitHub Pages 想定・未公開）：https://harugreed.github.io/coconala-portfolio/works/writing/

## ファイル

| フォルダ | 内容 |
|---|---|
| it-article/ | IT解説記事「社員10人の会社が業務効率化ツールを選ぶときの5つの手順」（約3,000字） |
| seo-article/ | 検索意図の分析メモ・見出し構成案・SEO記事（約2,500字） |
| product-review/ | 商品紹介文・レビュー記事（各約1,000字、架空の商品） |
| business-docs/ | 案内メール・依頼文・議事録（敬語の確認記録つき） |

## 書き方の方針

- 列挙は「、」「・」でつなぎ、「と、」を使わない。価格は「〜から」を付けず言い切る
- 具体的な数字・手順で書き、根拠のない相場の数字は書かない（SEO記事の数値は出典を明記）
- 会社名・人名・商品は架空。レビュー記事は文体見本で、実在の商品の評価ではない

## 応募時の紹介文（3行）

IT解説記事・SEO記事・商品紹介文・レビュー記事・ビジネス文書の自主制作サンプルです。
SEO記事は検索意図の分析メモと見出し構成を先に作り、費用の数値は公開ページで確認した出典を付けています。
ビジネス文書は案内メール・依頼文・議事録の3形式で、敬語の確認記録を添えています。
